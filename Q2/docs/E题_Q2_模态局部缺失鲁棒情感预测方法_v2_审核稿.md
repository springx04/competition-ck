## 1. 建议审核通过的主方法

### 1.1 方法概括

**采用附件2的官方 `aligned_50`，统一从 `text_bert` 编码文本；在任何可传播上下文的编码之前构造连续缺失，保留50个位置完成共享/特有语义分解、跨模态局部补偿与补偿可信度融合，最后进行片段级三分类和强度回归。训练使用原观测—受损双视图及EMA教师，专项推理仅保留一个学生预测器。**

本稿建议将方法称为“**连续缺失感知的跨模态补偿与可信融合方法**”。它是参考EBMC分解与增强思想的任务适配方法，不能称为“直接运行原版EBMC”。

核心问题分成四步：

1. **哪里还有信息？** 用当前输入构造可用性状态；人工缺失真值只用于训练监督和实验统计。
2. **缺失部分能从哪里补？** 从其他模态的可用共享语义、本模态剩余上下文推断情感表示，不生成原始声音或人脸特征。
3. **补出的表示值不值得用？** 用已知遮蔽位置上的补偿误差训练可信度估计，区分原观测、补偿和仍不可用三种来源。
4. **最终判断是否稳定？** 同时用真实标签和完整度更高的教师目标训练，检验缺失类型、位置和跨度引起的性能变化。

### 1.2 明确取舍

| 审核项 | v2的建议选择 | 原因 |
| --- | --- | --- |
| 主输入 | `aligned_50`，train/valid/test/附件3/附件4保持一致 | 50位置便于局部缺失分析；附件3文本入口与训练提前统一 |
| 文本编码器 | 核验兼容的BERT；主方案冻结其权重 | train仅3395条，先控制训练规模；内容缺失仍须重新编码 |
| 主网络 | 位置感知编码 → MSD → 局部补偿 → 可信融合 → 池化 → 双任务头 | 局部运算完成前不压成单个向量 |
| MSD | 复用双投影核心，改造掩码池化及辅助目标 | 原实现不能正确排除本题各模态的局部不可用位置 |
| CCE | 保留“共享语义帮助另一模态”的思想，重构为观测来源受限的跨注意力补偿器 | 原CCE是MLP反事实增强损失，不是缺失位置重建器 |
| 可信度 | 估计补偿表示相对教师目标的误差 | v1的自由方差缺少明确监督；也不能把补偿位置再乘原观测掩码清零 |
| 教师 | 一个原观测视图EMA教师，仅训练使用 | 不沿用EBMC的固定第一阶段教师，也不叠加两套蒸馏体系 |
| EMC | **独立可选扩展，暂不放入必选主线** | 它是训练正则项；原代码的批间预测方差不是局部不确定性，强行均衡受损模态可能误导训练 |
| Soft-MoE、原IMTD | 不作为首选必备模块 | 原路由不是归一化模态贡献，原IMTD不是局部概率表征；先避免与新融合、EMA重复 |
| 验证 | 原观测表现、受损表现、退化量、组件消融一起报告 | 鲁棒性不能仅靠一个总分或个别专项案例证明 |

EMC转为可选并非认定其无效，而是把“方法成立所必需的部分”和“可能进一步改善的部分”区分开。是否最终纳入由附件2 valid的独立对照决定，不因它出现在原论文名称中就默认有效。

### 1.3 相对v1修正的关键问题

| v1中的问题 | v2的修正 |
| --- | --- |
| 图中先编码/MSD，再生成受损视图 | **先修改输入，再分别编码**，防止邻近位置已携带被删除的内容 |
| 以三模态同为50步认定逐位置物理严格对应 | 只采用官方序列坐标；跨注意力允许访问其他可用位置，不硬锁同索引 |
| `r=U·…`使所有缺失位置权重为0 | 原观测与补偿使用不同来源状态；可用补偿获得非零但可降低的权重 |
| 预测局部方差，却没有定义其训练目标 | 用明确的补偿残差训练误差估计；不宣称得到校准的概率方差 |
| 把EMC画为推理中的串行模块 | EMC若采用，只作为训练侧辅助损失，不依赖专项样本标签 |
| 认为MSD、CCE可沿原封装直接复用 | 根据实际代码标明早池化、普通均值、MLP交换、教师加载等改造点 |
| 使用缺失长度/位置，却没交代专项如何获得 | 模型只接收当前输入可推断的状态；真实P与遮蔽前长度留在损失/统计侧 |
| 缺失时长、消融和选择规则较笼统 | 区分跨度与实际新增删除率，控制同样本同扰动，定义选择顺序及未定义指标处理 |

### 图6 可信度如何被训练，为什么补偿不会再次被清零

```text
只在训练的已知遮蔽位置：
  学生补偿F̂ + 教师原观测F̄
              |
              v
  归一化表示差异 e = ||n(F̂)-n(F̄)||²/d
              |
              +.. 停止梯度 ..> 误差估计器的监督目标

任意前向（含专项）：
  当前可用状态 + 来源内容 + 补偿表示
              |
              v
         非负误差估计 ê
              |
              v
         补偿可信度 1/(1+ê)

进入融合的三种情况：
  原观测U=1           --> F，来源=observed，可信系数=1
  U=0且有可用补偿B=1  --> F̂，来源=compensated，可信系数=1/(1+ê)
  U=0且B=0            --> 无内容，来源=unavailable，权重=0

可信系数再与任务学习的内容得分结合，形成当前位置模态权重。
“原观测系数=1”只是来源基准，不表示该观测一定正确或有情感价值。
```

## 3. 题目与数据事实：本方法必须适应的约束

本节以已有[数据核查MD](C:/Users/30738/Desktop/sm/中文题目/E题/doc/E题数据细节.md)为事实来源。本轮未重新加载约1GB/2.9GB的PKL，也未将公开完整版MOSEI的默认设置套到本题。

### 3.1 输入、标签和划分

| 内容 | 已总结的本题事实 | 方法含义 |
| --- | --- | --- |
| 附件2划分 | train/valid/test = 3395/728/727；来源视频不交叉 | 保留原划分，不重新打散，也不在train+valid重训后继续拿valid选模 |
| 分类 | `0=Negative, 1=Neutral, 2=Positive` | 三分类，不能沿用正负二分类指标 |
| 回归 | `[-3,3]`；真实分类与负/零/正一致 | 双任务都是片段级，无逐位置情感标签 |
| aligned输入 | `text_bert(N,3,50)`、`audio(N,50,74)`、`vision(N,50,35)` | 三模态保持位置索引，投影至共同隐藏维度d |
| 预计算text | `(N,50,768)`，包含padding位置也可能非零 | 不用非零判断文本有效性；主模型不走此字段 |
| 附件3对齐版 | `test`外层，已有样本维1；无text/raw_text/id/标签/长度 | 文本从三路BERT输入编码；结果ID取文件名 |
| 附件3文本类型 | float32存储，但值均为整数 | 按词元ID/注意力/分段ID语义转换；不是连续文本特征 |
| 原生视觉全零 | 附件2train/valid/test分别110/15/28条 | 原观测视图也可能不完整，不能假定每条都能监督视觉恢复 |
| 附件4 | 无test外层、无样本维，20条；对齐版13号视觉全零 | 数据适配到同一预测器；13号不能产生原始视觉证据 |
| 缺失真值 | 附件3没有真实P、遮蔽前长度或完整对应样本 | 只能从当前输入建立工作状态，不能精确反推人工缺失率 |

附件3的文本中没有观察到“非零列范围内部三路同时全零”的洞。这不证明文本未受任何语义损坏，也不支持虚构其已知文本缺失率。文本缺失规律由自建有控制的valid实验回答。

### 3.2 版本与文本入口

主版本选择aligned是基于接口和局部分析便利性，不是提前认定其性能优于unaligned。后者如比较，应独立训练、独立验证，所有专项也使用未对齐版；不把两版本混作本模型的对比学习双视图。

统一文本入口是 `text_bert → 同一个兼容编码器`。候选 `bert-base-uncased` 必须先用附件2 train中的raw_text与存储IDs核对词表、大小写、特殊词元和截断规则；兼容性目前是**待核验条件**，不是本轮已完成事实。不能因为输出都是768维就把自算表示和官方text混接。

正文中的“冻结BERT”表示不更新预训练权重，不表示可以用完整文本缓存代替受损文本的重新计算。内容发生变化后，所有上下文表示均要由受损输入重新产生。BERT输入确有独立的input IDs、attention mask与token type IDs，见[官方BERT接口说明](https://huggingface.co/docs/transformers/model_doc/bert)。

## 5. 状态与掩码：同时满足训练可监督、专项可推理

### 5.1 先区分概念状态与实际可获得状态

沿用Q1语义：`V`表示结构有效，`O`表示原观测可用，`P=1`表示本队新增遮蔽。在这些信息已知时：

\[
U_m(t)=V_m(t)O_m(t)[1-P_m(t)].
\]

但官方aligned并未完整提供音视频V/O，附件3更没有真实P。因此，这个等式是**状态语义**，不是声称每个量都可从专项文件准确读出。本方法另外定义统一的当前输入适配器：

\[
\mathcal A(X^{v})=(U^{v},J^{v},q^{v}),\qquad v\in\{0,P,\mathrm{special}\}.
\]

- `U^v_m(t)`：当前输入中允许作为内容证据的位置，0/1；来自已知状态或下表的工作推断。
- `J^v(t)`：当前有依据保留为可定位位置的工作域；不等于精确真实时长。
- `q^v`：从当前U/J计算的可用比例、缺口长度与相对位置等摘要，不包含遮蔽前真实长度。

这里v只表示采用哪个输入视图，**不作为“这是训练人工缺失”的标志喂给模型**。同样的当前输入应经过同样的适配规则。

### 5.2 建议采用的工作规则

| 输入情况 | 工作规则 | 可作出的判断及限制 |
| --- | --- | --- |
| 文本内容词元 | 使用存储注意力信息，排除PAD、CLS、SEP及本方案用于删除的MASK词元 | U表示可用内容，不以编码结果非零为依据；自然UNK不能自动认定为人工缺失 |
| 文本特殊词元 | 可保留为编码器结构用途，不进入内容池化、删除率或Q3词证据 | CLS/SEP的上下文向量不是某个原文词 |
| 音/视觉非零行 | 在无额外提取日志时，暂作为可用向量 | 不据此认定质量高或物理含义已知 |
| 音/视觉整行全零 | 本题工作规则按“无可用内容证据”处理，记为推断状态 | 不能断言是人工删除、无脸、静音或padding中的哪一种 |
| 整条视觉全零 | 视觉原观测U全0；其他模态继续使用 | 无视觉恢复真值；补偿也不能变成真实视觉证据 |
| 三模态尾部均无内容支持 | 不做位置压紧，不声称已恢复原真实长度 | 无定位依据的尾部不作为补偿查询或池化内容 |

**零行规则是官方数据缺乏状态日志时的建模约定，不是“物理零值必然无效”的事实。** Q1有提取日志时仍按日志认定合法静音、零AU等观测，不能反过来改成零值判缺失。对Q2应在valid比较合理的零行处理变体，说明性能对这一约定的敏感性；没有缺失真值就不能报告掩码识别准确率。

J的推荐定义为：当前文本有结构位置证据的非边界词元槽位（包括保留槽位的MASK），与音频/视觉非零观测位置的并集。文本padding不能直接当作音视频padding；只要某模态该位置有真实输入，就保留它。

若某段三路都没有内容或结构证据，则不能仅凭训练时记得它曾经有效而让学生知道真实长度。该位置不参加补偿/池化，样本仍通过其他位置预测。对未知尾部，这种保守处理会遗漏部分可能的缺失位置，应如实作为数据限制。

### 5.3 哪些状态进入网络，哪些只进入监督

| 内容 | 编码/补偿/融合能否使用 | 用途 |
| --- | --- | --- |
| 当前U、J、当前位置编号 | 能 | 证据选择、查询生成、池化 |
| 由当前U/J算出的缺口摘要q | 能 | 估计补偿难度；名称为当前不可用比例，不冒称人工缺失率 |
| 原观测输入X⁰中的被删值 | 受损学生不能 | 仅原观测学生分支、教师分支使用 |
| 已知新增P、原可用U⁰ | 不能作为额外受损输入 | 定义监督位置、控制变量和实验分母 |
| 教师latent、教师预测、真实标签 | 不能作为预测输入 | 构造训练损失 |
| `known/inferred`及原始状态原因 | 主线不以“人工/天然”真因作特征 | 用于记录与分层分析，防止训练获得专项没有的额外提示 |

对可识别的新增音视频置零，通常得到 `U^P=U⁰(1-P)`；实现核验应确认当前输入适配能得到这一结果，而不是只在训练直接传一个理想U绕过推断流程。

### 5.4 标准化和掩码作用点

音/视觉统计量只从train原可用位置估计；各划分使用相同统计量。先依据原数值和结构识别当前状态，再标准化可用观测，最后重新屏蔽不可用行。投影偏置、位置编码或残差产生非零值，不能使不可用行重新获得“原观测”身份。

编码器的Key/Value仅来自可用内容；补偿Query可以位于缺口。MSD池化、辅助任务、跨模态来源、最终池化都使用各自相应的掩码，不能只在读取数据时乘一次零就结束。没有可用Key/Value时，该操作定义为不产生内容，避免对全空集合求注意力分布。

## 6. 连续缺失模拟：不压紧位置、不泄漏原内容

### 6.1 区间与实际新增删除率

设原观测工作位置域的最小包络为 `[a_i,b_i)`，长度 `L_i=b_i-a_i`。在**原存储位置轴**上选择模态集合M和连续区间 `[s_m,e_m)`：

\[
P_{i,m}(t)=U^0_{i,m}(t)\,\mathbf1\{s_m\leq t<e_m\}.
\]

跨度比例与实际新增删除率分别为：

\[
\rho^{\mathrm{span}}_{i,m}=\frac{e_m-s_m}{L_i},\qquad
\rho^{\mathrm{drop}}_{i,m}=\frac{\sum_tP_{i,m}(t)}{\sum_tU^0_{i,m}(t)}.
\]

分母为0时，标记“该模态原已不可用”，不计算其新增删除率。区间可以跨过天然空洞，但只删除其中原可用内容；不能从离散可用行中抽k行并压紧后声称连续缺失。文本原可用分母不计CLS/SEP/PAD。

图4中原可用位置共8个，跨度为4个位置，新增删除率为3/8。这个例子说明“遮了4步”和“丢了50%观测”不是同一件事。

### 6.2 操作必须发生在全部上下文传播之前

音/视觉：在输入特征序列上将区间内选定行置为不可用，然后重新执行投影、时序编码和MSD。先完整运行Transformer或卷积再删隐藏向量，也会发生上下文残留。

文本：在存储词元序列上将内容区间替换为兼容的MASK词元，保留原位置、分段ID和结构槽位；BERT的内容Key可用掩码排除被删内容槽位，边界特殊词元按编码器规则保留。重新编码之后，缺口位置的BERT输出仍不能直接冒充原文本观测；它由独立补偿查询处理。

这一定义模拟“给定官方词元位置中的内容不可用”，不删除词元后重新分词压紧序列。自然语言中对被删内容的上下文推断是允许的，但读取完整文本缓存中的残留信息不是本实验要评价的能力。BERT具备双向上下文依赖，见[官方说明](https://huggingface.co/docs/transformers/model_doc/bert)。

Q2的连续单位暂定为官方位置，未核验完整word/subword映射前，不宣称每个区间都是整词删除。可另做完整词组边界删除的敏感性实验，但需要train/valid内真实可核验的映射。

### 6.3 课程与场景覆盖

```text
监督预热：原观测双任务为主，先建立可学习的情感表示
    ↓
轻缺失阶段：加入单模态短区间；开启局部补偿和误差学习
    ↓
混合阶段：覆盖不同位置与跨度，逐步加入双模态重叠缺失
    ↓
稳定阶段：继续混合原观测、短/中/长区间及不同模态组合
          不把训练后期全部换成严重缺失
```

每阶段保持原观测监督；遮蔽采样与真实情感标签独立。双模态既覆盖同步区间，也用少量错开区间检验分布变化。整模态删除与三模态同段删除属于压力测试，不替代题目要求的局部缺失主实验。

课程是待验证的训练策略，不预先声称一定优于从开始均匀采样。对照时要尽量保持总训练步数、最终场景范围和累计受损样本量相近，避免把训练预算差异当成课程收益。

## 7. 位置感知编码与MSD：保留局部结构

### 7.1 三模态编码

对当前视图分别得到：

\[
H_m=E_m\bigl(\operatorname{Proj}_m(X_m)+p(t),U_m\bigr)
\in\mathbb R^{50\times d},\qquad m\in\{T,A,V\}.
\]

文本的X先经过兼容BERT；音/视觉X是标准化后的74/35维向量。`p(t)`表示官方位置而非秒数，模态身份另外保留。BERT已有位置机制，进入共同隐藏空间后仍需明确三模态的来源位置；不默认音视频已有同等位置编码。

该编码器保留双向上下文，因为任务是整段离线预测，不是在线因果预测。此时可以利用缺口前后内容，但不读取未来测试样本或被删除的原值。注意力作为查询—键值交互的基础来源见[Transformer原论文](https://arxiv.org/abs/1706.03762)；本稿的缺失来源约束是任务适配设计。

### 7.2 分解与用于后续处理的表示

\[
C_m=D_m^c(H_m),\qquad S_m=D_m^s(H_m),\qquad
F_m=\operatorname{LN}(C_m+S_m).
\]

复用EBMC两路投影核心；U为0的输出不进入原观测来源集合。分解提供两个职责：其他模态优先提供C，本模态可用上下文提供C和S。不能要求另一模态完全恢复目标模态独有且已丢失的信息。

### 7.3 MSD辅助目标的具体口径

辅助目标主要在**原观测学生分支**计算，避免把严重受损的零占位强制对齐。定义模态掩码均值：

\[
\operatorname{MP}_m(Z)=\frac{\sum_tU^0_m(t)Z(t)}{\sum_tU^0_m(t)}.
\]

只对分母非零的样本计算相应模态辅助项。

此处辅助目标使用U⁰；第8节前向补偿中出现的MP使用**当前视图U**重新池化，不能使用原观测分母、原观测向量或完整视图缓存。第9.4节的原观测协调项仍使用U⁰。

1. **共享表示对齐**：同一样本两模态的 `MP(C)` 为正对，批内其他有观测样本为负对，使用对称样本级InfoNCE。两模态的正负候选均来自同一有观测样本集合；至少两个样本才形成该项。它对齐的是同一片段语义，不是要求所有同索引位置相等。
2. **特有表示去相关**：对两模态均可用的样本，约束 `cos²(MP(S_m),MP(S_n))` 的平均值；沿用EBMC“减少冗余”的意图，不夸大为统计独立证明。
3. **单模态辅助预测**：各 `MP(S_m)` 通过训练用分类/回归头预测片段标签，只对该模态有观测的样本监督。标签不复制成逐词/逐帧真值。

共享目标可写为：

\[
\ell^{m\to n}_i=-\log\frac{\exp(\operatorname{sim}(c_{i,m},c_{i,n})/\tau)}
{\sum_{j\in\mathcal I_{mn}}\exp(\operatorname{sim}(c_{i,m},c_{j,n})/\tau)},
\quad c_{i,m}=\operatorname{MP}_m(C_i).
\]

在模态对和两个方向上平均得到 `L_shared`。这里使用标准的样本对比定义，属于对原代码相似度目标的改造；不照搬其批级比值计算并声称两者完全等价。不同样本可能具有相同情感，对比目标不能无限增大权重，应以主任务表现验证其必要性。

\[
L_{MSD}=L_{shared}+\lambda_{sp}L_{specific}+\lambda_{uni}L_{unimodal}.
\]

这些辅助损失不要求严格逐时刻跨模态对齐，也不引入aligned/unaligned混用。若消融表明去相关或对比目标损害预测，应去掉对应辅助项，保留实际有用的分解结构；不能把模块越多当作方法更充分。

## 8. 局部补偿与可信融合：方法的主要新增部分

### 8.1 补偿查询和可用来源

仅对 `J(t)=1且U_m(t)=0` 的位置提出补偿请求。目标Query由模态标识、位置编码及本模态可用上下文构成：

\[
Q_m(t)=W_Q[\,p(t);e_m;\operatorname{MP}_m(F_m)\,].
\]

当前模态完全不可用时，上式上下文项采用无观测占位，并显式保留这一状态；不把该占位作为证据。来源集合：

\[
\mathcal K_m=\{C_n(u):n\ne m,U_n(u)=1\}
\cup\{[C_m(u);S_m(u)]:U_m(u)=1\}.
\]

不同来源投影到共同键值空间，并保留来源模态和原位置。跨模态使用共享分量，是为了避免把其他模态的特有分量直接解释成目标模态真实观测。目标模态特有线索只能由其剩余上下文帮助推断。

\[
\widehat F_m(t)=G_m\left(\operatorname{MHA}(Q_m(t),K_m^{att},V_m^{att};\mathcal M_m)\right).
\]

`K_m^{att},V_m^{att}`分别为投影后的注意力Key/Value，与结构有效掩码V区分。掩码 `𝓜_m` 只放行来源集合中的可用位置。可以给相近官方位置软偏好，但不把同索引设成唯一可见来源；官方词/子词和音视频逐行对应尚未完全证实。

采用**单轮补偿**：全部补偿只读取补偿前的原观测来源。禁止某模态刚补出的内容立即成为另一模态的恢复证据，避免循环放大无依据的信息。自然全零模态可以由其他模态得到替代表示，但这只是预测用途的推断。

### 8.2 只在有真实原观测目标的位置监督补偿

令 `B_m(t)=1` 表示该位置完成了有非空来源支持的补偿。训练监督集合为：

\[
\Omega=\{(i,m,t):P_{i,m}(t)=1,\ U^0_{i,m}(t)=1,\ B_{i,m}(t)=1\}.
\]

教师从X⁰得到相同位置的补偿前表示 `F̄_m(t)`。用无可学习缩放的逐位置归一化 `ν` 统一比较尺度：

\[
e_{i,m,t}=\frac1d\left\|\nu(\widehat F_{i,m}(t))-
\operatorname{sg}[\nu(\bar F_{i,m}(t))]\right\|_2^2,
\qquad L_{span}=\operatorname{Mean}_{\Omega}e_{i,m,t}.
\]

无监督位置时该项不参与当批平均；归一化与平均均只针对合法目标。为避免长缺口或长样本独占损失，推荐先在每个样本—模态的监督位置内平均，再在非空样本—模态间平均；后文的 `Mean_Ω` 采用这一口径。

原本无脸/全零视觉处没有观测目标，即使教师生成了一个补偿，也不能把它当作恢复真值加入Ω。教师目标是学习到的情感表示，不是真实声学/视觉生成标签；`L_span`降低也不自动证明情感预测改善。

### 8.3 用可验证的误差代理代替无监督的自由方差

误差估计器使用当前内容、来源摘要和缺口状态，输出非负值：

\[
\widehat e_m(t)=\operatorname{softplus}
\bigl(R_m(\operatorname{sg}[\widehat F_m(t),\mathrm{context}],q_m(t))\bigr),
\]

\[
L_{cal}=\operatorname{Mean}_{\Omega}
\operatorname{SmoothL1}(\widehat e_m(t),\operatorname{sg}[e_m(t)]).
\]

`L_cal`只更新误差估计器，不通过其输入反向改变补偿器来“迎合误差预测”。融合使用的误差系数也停止梯度，因此估计器不能仅为了降低任务损失随意把所有误差报成0。补偿器由真实标签任务和 `L_span` 学习。

这种量称为**补偿误差代理/可信度系数**，不是贝叶斯方差、情感置信区间或观测真实性概率。它在人工遮蔽上有监督，推广到天然不可用和专项未知扰动仍有分布差异，需要valid分层分析。

### 8.4 原观测、补偿、不可用分别进入融合

定义参与融合的表示与系数：

\[
\widetilde F_m(t)=
\begin{cases}
F_m(t),&U_m(t)=1,\\
\widehat F_m(t),&U_m(t)=0,B_m(t)=1,\\
0,&\text{其余情况},
\end{cases}
\]

\[
r_m(t)=
\begin{cases}
1,&U_m(t)=1,\\
[1+\operatorname{sg}(\widehat e_m(t))]^{-1},&U_m(t)=0,B_m(t)=1,\\
0,&\text{其余情况}.
\end{cases}
\]

再用内容得分 `g_m(t)` 区分该表示对当前预测的价值：

\[
\alpha_m(t)=\frac{r_m(t)\exp g_m(t)}{\sum_nr_n(t)\exp g_n(t)},
\qquad Z(t)=\sum_m\alpha_m(t)\widetilde F_m(t).
\]

g由当前表示、模态身份和来源状态学习，不读真实标签或教师输入。原观测系数为1只是参考尺度，内容得分仍可降低噪声观测的权重；补偿系数为正并非强制模型相信补偿。

所有分支系数均为0的位置不做上述除法、不参加最终池化；不人为填成各1/3。若整条样本无任何内容，则保留记录，以train类别先验和train强度中位数作明确标注的无信息输出；不伪造模态依据。这一分支用于使方法在空集合情形下有定义，不代表本题已有此类实测样本。

相对融合系数不能反映绝对置信程度：即使几个低可信补偿归一化后权重和为1，也不能据此说预测可靠。预测可信程度和鲁棒性仍依赖任务评价。

### 8.5 为什么这条链路在方法上闭合

学生输入可推断状态 → 只从当前可用来源补偿 → 补偿误差有训练目标 → 三种来源有明确融合规则 → 真实标签验证最终收益。每个新量都有来源和用途，推理不需要教师、标签或真实P。

本方法不能创造原本已丢失且其他模态完全不含的独有情感线索。教师一致性是软约束；严重缺失后性能下降属于可能结果，不预先承诺任意缺失强度下保持完整性能。

## 9. 双视图训练、双任务输出与总目标

### 9.1 两个学生视图都接受真实标签监督

令 `p^v,ŷ^v=Fθ(X^v)`。融合后对有可用表示的位置取掩码均值，得到片段向量z，再输出：

\[
p=\operatorname{Softmax}(W_cz+b_c),\qquad
\widehat y=3\tanh(w_r^\top z+b_r).
\]

分类输出 `argmax(p)`，对应Negative/Neutral/Positive；回归头保持连续范围 `[-3,3]`。不沿用EBMC的二分类阈值或七级取整。任务损失：

\[
\ell_{task}(p,\widehat y;y_c,y_r)
=\operatorname{CE}(p,y_c)+\lambda_r\operatorname{Huber}(\widehat y,y_r),
\]

\[
L_{sup}=\operatorname{Mean}_i\left[
\ell_{task}(F_\theta(X_i^0),y_i)
+\lambda_{aug}\ell_{task}(F_\theta(X_i^P),y_i)\right].
\]

不只监督受损分支，否则原观测教师可能跟随一个尚未学会正常输入的学生。CE主方案先不加类别权重，另以train统计的权重作可选对照；有效与否由三分类Macro-F1等共同判断。

两任务共享z，但独立头可能产生“类别与回归符号不一致”。主方案保留原始两头输出，并报告这一比例及中性样本表现；不在看过专项预测后偷偷翻转符号、改标签或把小正值归成中性。若审核要求提交结果严格成对一致，则应另行选定一致决策模型，在valid完整重评两任务，不能把它当作无影响的导出修补。

### 9.2 EMA教师与一致性

监督预热后由学生初始化同结构教师，每次学生更新后：

\[
\bar\theta\leftarrow\eta\bar\theta+(1-\eta)\theta.
\]

教师采用eval且不参与反向传播；冻结的文本编码器保持同一套确定权重。教师输入X⁰，学生输入Xᴾ。权重平均教师的来源见[Mean Teacher原论文](https://arxiv.org/abs/1703.01780)；将它用于本题有标签的原观测—连续受损训练，是本方案的适配，不意味着必须引入额外无标签数据。

预测一致性定义为：

\[
L_{cons}=\operatorname{Mean}_i\,w_i\left[
D_{KL}(\operatorname{sg}[\bar p_i]\Vert p_i^P)
+\lambda_{cr}\operatorname{Huber}(\widehat y_i^P,\operatorname{sg}[\bar y_i])
\right].
\]

教师可能判断错误，因此不把它当作额外真值。建议使用仅在训练损失侧计算的软权重：

\[
w_i=\operatorname{sg}\left[\bar p_i(y_{c,i})
\exp\left(-|\bar y_i-y_{r,i}|/6\right)\right].
\]

6是强度取值范围的宽度，用于尺度归一；该权重不是校准正确率。真实标签监督始终保留，一致性权重从预热后逐步增加。严重缺失下允许预测与教师不同，不额外强制整个融合向量完全一致。

训练结束后，**主方案固定部署学生**，valid也以学生受损前向进行模型选择。教师原观测输入只是训练信息，不允许用其结果替代学生的缺失实验结果。教师不进入附件3/4推理。

### 9.3 总损失与每一项的职责

\[
\boxed{L=L_{sup}+\lambda_M L_{MSD}+\lambda_S L_{span}
+\lambda_E L_{cal}+\lambda_C L_{cons}.}
\]

| 项 | 使用数据/位置 | 更新对象 | 回答的问题 |
| --- | --- | --- | --- |
| `L_sup` | train原观测与受损视图的片段标签 | 学生编码、分解、补偿、内容融合、预测头 | 最终分类与回归是否准确 |
| `L_MSD` | 原观测学生中实际有观测的模态 | 编码、分解和辅助头 | 共享语义能否协同，特有表示是否保留任务信息 |
| `L_span` | Ω中的已知新增缺失位置 | 学生补偿器及其观测来源表示 | 能否从剩余内容推断教师情感表示 |
| `L_cal` | 同一Ω，误差目标与输入停止梯度 | 误差估计器 | 能否估计补偿结果的表示误差 |
| `L_cons` | train两视图片段预测 | 学生预测路径；不更新教师 | 受损输出是否避免不必要偏移 |

这里没有另加一个无定义的 `L_trust`，也没有把原CCE重构与新的 `L_span` 重复计算。所有参数学习仅来自train；损失权重、隐藏维度、层数、优化器等具体值留给审核后的实现方案。

### 9.4 可选EMC的限定版本

如果主方法稳定后仍观察到某模态的有效观测长期未被利用，可以比较**EMC启发的简化协调正则**。仅对同一样本三模态均有原观测的原观测学生分支计算，不把补偿内容混入单模态能量：

\[
E_{i,m}=a\,\|\operatorname{MP}_m(F_i)\|_2^2/d
+b\,\ell_{task}(\operatorname{Head}_m(\operatorname{MP}_m(F_i)),y_i),
\]

\[
L_{coord}=\operatorname{Mean}_i\sum_{m<n}(E_{i,m}-E_{i,n})^2.
\]

它不采用原代码的批间回归方差，也不默认加入二阶梯度范数项；因而必须标作简化改造，不能冒称原EMC的完整复现。其预测头和损失仍只在训练侧存在。

能量接近不等于三模态同样可靠；该目标也可能使强模态变差。只有在同预算对照中对正常/缺失任务有稳定收益才考虑纳入，论文同时展示成本。**本稿必选总损失不含此项，原IMTD也不与EMA另行叠加。**

## 10. 训练、验证、专项推理各自能做什么

| 阶段 | 输入 | 可用监督/操作 | 不能混入的内容 |
| --- | --- | --- | --- |
| train | 附件2 train aligned | 标签、已知人工P、EMA目标；拟合模型和标准化 | valid/test/专项标签或专项伪标签 |
| valid | 附件2 valid aligned | 固定人工扰动、指标、解释干预；用于选择 | 不通过反向传播更新模型；不把完整视图内容送入受损预测 |
| test | 附件2 test aligned | 方法确定后的留出评价 | 不依其表现调整方案，再把同一test称独立评价 |
| 附件3 | 30条对齐专项特征 | 同一适配、标准化、文本编码、学生推理 | 真P、完整样本、教师输入、标签、跨库近邻找回原内容 |
| 附件4 | 20条对齐专项特征及视频 | 同一学生预测，Q3定位与回看 | 不根据专项解释案例反复优化模型后继续当独立展示 |

最终Q2结果一文件一行，建议字段：`sample_id, feature_version, pred_label, pred_score`，可加三分类概率；共30行。`sample_id`保留原文件名去扩展名，`feature_version=aligned`。这是建议列名，当前没有官方逐列模板。

专项只跑**已经确定的预测方法**；不得根据30条的输出分布再调中性阈值、融合系数或缺失规则。原生零观测和推断状态可单独留作分析记录，不添加虚构的真实缺失率或专项准确率。

## 11. 如何验证：既回答题目，也检验新增模块

### 11.1 题目要求的三个控制变量

建议在valid上建立以下规则化实验网格；具体网格密度可在实现方案中结合计算成本确定，但不能根据哪组结果好看临时改变报告口径。

| 变量 | 主实验设计 | 其余控制条件 |
| --- | --- | --- |
| 缺失模态 | T、A、V、T+A、T+V、A+V | 同一样本、同一位置区间、同一跨度；双模态主实验使用同步区间 |
| 缺失位置 | 前、中、后 | 同一模态集合和跨度；起点分别为a、中部居中、b减跨度 |
| 缺失跨度 | 由短到长，例如20%、40%、60%、80%，加原观测0% | 按原工作位置域L计算整数跨度；同时记录实际新增删除率 |
| 额外压力场景 | 双模态错开、整模态、三模态同段、未见过的跨度 | 单独报告，不与主实验平均后掩盖局部场景 |

“时长”在本题官方特征上只能报告**连续位置数、位置域跨度比例及新增删除率**。没有原时间戳，不能写成丢失了几秒，更不能用位置数乘视频时长假造精确秒级结论。

取整导致多个比例得到同一删除区间时，合并或标明相同区间，不能重复计权。未真正删除内容的条件保留为“无新增损伤”，不混称有效缺失。

### 11.2 同跨度不一定同删除量：比较必须有共同样本口径

不同模态的天然可用位置不同，固定同一时间位置区间后，实际删除率可能不同。因此同时给出：

1. **全valid应用结果**：所有样本均保留，反映真实原生缺失分布下表现；列出原已不可用和无新增损伤数量。
2. **配对效应结果**：一次比较使用同一批、所比较条件均实际新增删除的样本；选取仅依赖输入状态与区间，不依赖标签、预测正误或误差大小。
3. **删除量说明**：报告各条件实际删除率分布。若要声称“某模态更敏感”，再按相近实际删除率分层或匹配，避免仅因它被删得更多得出结论。

前/中/后比较也必须使用共同样本集合；不能分别挑各自最容易的样本。天然有空洞时不强求“固定跨度”和“固定删除率”同时成立，而应明确当前控制的变量。有限50位置下，这一点比增加更多复杂评分更重要。

### 11.3 指标与不确定性

主指标：三分类Accuracy、Macro-F1、Weighted-F1、连续MAE和Pearson相关系数。Macro-F1明确按Negative/Neutral/Positive三类报告，并给出每类F1与支持数；小分组缺少类别时注明，不只报一个不稳定均值。

原观测—受损退化量：

\[
\Delta F1=F1_0-F1_P,\quad \Delta Acc=Acc_0-Acc_P,
\]
\[
\Delta MAE=MAE_P-MAE_0,\quad \Delta PCC=PCC_0-PCC_P.
\]

原观测指同一真实样本的X⁰，不是虚构的三模态全完好状态。性能可能偶尔改善，负退化量也照实报告。Pearson对常量预测或不足以计算的分组标为未定义，不用0替代；附该组规模和预测方差。

核心方法和关键对照建议至少3个训练随机种子；评估使用相同样本和相同扰动清单。对主要模型差异可按来源video_id做配对重采样，避免同源片段被当作完全独立样本；训练随机性和评估采样波动分别说明。不能只以一组最佳种子宣称模块稳定有效。

### 11.4 必要对照与消融：控制模型容量和训练预算

下表是实验比较模型，不要求引入另一套工程基线文件或版本机制。

| 对照 | 保持不变/改变什么 | 能检验什么 |
| --- | --- | --- |
| 简单三模态模型 | 同文本入口、编码预算、双任务与当前掩码；只做各模态池化后融合，原观测训练 | 不增加鲁棒机制时的参照性能 |
| 简单模型+连续增强 | 仅增加同一连续缺失训练 | 收益是否主要来自数据增强 |
| 主模型去补偿 | 保留MSD和训练视图，缺口分支不参与融合 | 局部补偿是否超出直接依赖剩余模态 |
| 主模型去误差系数 | 保留同样补偿，补偿系数固定为1 | 学习补偿可信度是否必要 |
| 主模型去MSD | 使用直接投影表示，其余保持 | 共享/特有分解是否值得增加复杂度 |
| 主模型去预测一致性 | 去 `L_cons`，保留教师仅作span目标 | 教师预测一致性是否有独立贡献 |
| 主模型去latent监督 | 去 `L_span`；误差估计仍可单独使用停止梯度残差目标 | 显式补偿表示监督是否改善最终任务 |
| 全部去教师 | 同时去span目标、误差校准及预测一致性，补偿仅由标签学习 | 完整教师体系的总贡献；不能解释成只去掉一个损失 |
| 均匀缺失采样 vs 课程 | 同场景范围与接近的受损样本总量 | 课程安排本身是否有效 |
| 主模型+可选协调正则 | 只加入第9.4节的简化EMC | 是否有额外收益及成本 |

去教师时需要把补偿可信系数固定，不能继续保留一个没有监督目标的误差头。去补偿时相应 `L_span/L_cal` 无定义并一并移除，剩余损失保持可解释；消融表说明这些必然的联动，避免伪称完全单变量。

为控制训练预算，EMA体系之外的对照也应获得相近的受损样本和优化步数；报告参数量、训练时间及单条推理开销。Soft-MoE或完整EBMC适配复现可作为资源允许时的扩展，不是完成本题的前置条件，也不能直接引用原仓库二分类数字与本题三分类比较。

### 11.5 专门验证“补偿可信度”是否名副其实

在valid已知遮蔽位置上，以原观测视图生成参照表示，比较预测误差与实际补偿残差的分组趋势、排序相关及误差；同时比较固定系数、学习系数对最终Acc/F1/MAE的影响。原观测参照仅用于分析，不能进入受损前向。

需要回答两个独立问题：估计器是否能识别相对较差的补偿？这些估计是否真的改善预测？若只降低表示残差但不改善任务，不能宣称已证明鲁棒性；若误差排序不成立，则将该量降格为内部融合信号，或按消融结果移除。

自然全零视觉样本没有完整视觉latent真值，只能评价标签任务和可用模态依赖，不能把其他样本的人工遮蔽校准曲线当成它们的真实恢复精度。

### 11.6 选择规则与论文结论

建议先按原观测和受损两任务指标排除明显被其他候选全面支配的模型，再以**主实验有效场景的等权平均Macro-F1**为首要选模指标；相同时优先平均MAE较低者，再考虑原观测表现和模型规模。平均的场景集合及各场景样本口径在比较前确定，空条件不按0分填入。

这是明确的分类优先选择规则，强度回归仍逐项报告，不能隐藏两任务冲突。若审核希望两任务等优先，可改为报告Pareto候选并在实施前选定取舍；不在看到专项结果后改变选择口径。具体早停和并列容差属于下一阶段参数方案。

论文用“在本数据、本位置定义和本缺失机制下观察到……”表述规律。不能由位置前/后敏感性直接推出心理学因果，也不能预先写“文本一定最重要”“缺失越长必然严格单调变差”或“补偿必然改善”。

## 12. Q1—Q2—Q3怎样形成实际可验证的闭环

### 12.1 Q1到Q2：复用状态和方法，不混淆特征空间

当前Q1 v3为 `768维文本 + 25维声学 + 22维视觉`，最终是覆盖片段的50个相对时间窗；官方Q2输入为BERT词元入口、74维声学、35维视觉，50是官方序列位置。两者不是同一特征体系。

Q2继承Q1的内容：样本来源、位置类型、V/O/P语义、观测与占位分离、来源记录。不能继承的内容：未经验证的输入投影权重、全部100条训练数据、数值时间映射。附件1与附件2有18条已知重叠，其中7条属于test，更不能把整批100条加进Q2训练。

对应依据见[Q1方法稿](C:/Users/30738/Desktop/sm/中文题目/E题/doc/E题_Q1_多模态特征构建方法_v3_审核稿.md)及[Q1结果核验方案的闭环边界](C:/Users/30738/Desktop/sm/中文题目/E题/doc/E题_Q1_实现后测试_结果报告与收尾判定方案_v1.md)。这两份文件是方法/核验安排，本轮未获得并核验其实际运行结果，不能据此宣称Q1已完成提取或通过全部质量检查。

### 12.2 Q2到Q3：解释同一个最终学生

Q3优先固定Q2选定的学生编码器、补偿、融合和输出头，不另训一个不同预测器再把解释挂到Q2上。Q2应能够暴露以下方法层面的中间量：

| 信息 | Q3的用途 | 不能直接推出什么 |
| --- | --- | --- |
| 当前U/J及来源状态 | 排除padding和无观测位置；区分补偿 | 不能仅因某分支有值就说原模态有证据 |
| 原输入模态、位置及补偿来源索引 | 将模型运算连接到实际可用输入 | 注意力大小不等于因果贡献 |
| 融合前表示、局部权重、最终输出 | 选择归因目标、比较缺失前后变化 | 融合权重不等于模态重要性真值 |
| 固定的输入遮蔽方法 | 原输入级模态/片段删除干预 | 不能只删最终latent而称删除了原文本内容 |

**Q3归因的单位是原始可用输入，不能把补偿后的三条分支当作三份独立原始证据。** 例如视觉全零时，视觉补偿可能来自文本；视觉分支的融合权重不代表视觉提供了新证据。干预文本输入后应重新运行编码、补偿和融合，让依赖文本的补偿也随之改变。

Q3比较关键区间删除与同模态、同数量/长度、同替换方式的对照删除。分类贡献应固定解释原预测类别的分数，不能每次删除后改用新的argmax分数；回归贡献固定为同一连续输出变化。比较缺失前后贡献时同时保留未归一化影响量，不能只因三模态权重和为1就宣称其他模态补偿成功。

### 12.3 Q3到原素材：复用Q1定位过程，重新建立对应

附件4文本可以核验raw_text、存储词元与字符的关系，并借用Q1词级时间定位方法回到配套视频。音视频官方50位置到词/帧/秒的对应仍需独立证实；不采用 `t/50×视频时长` 作为精确证据。

若映射未能证实，应分别交代：已确定的模态作用、已确定的特征位置、候选原素材区间及其不确定性。只有候选区间时，不能宣称完全满足精确回溯。重提取附件4可帮助核验素材，但不能单独替换预测器的官方输入，再将新提特征解释成模型实际使用的特征。

附件4对齐版13号原视觉全零，应明确“无原视觉证据”；即使补偿分支参与预测，也只能回溯到实际供给信息的文本/音频，不能自动选择一张画面冒充模型视觉依据。

### 12.4 闭环证据应如何组织

建议用同一批valid样本串联：

```text
原观测状态与内容
  --> 原预测及原输入贡献
  --> 已知连续区间删除
  --> 新的可用状态、补偿来源与受损预测
  --> 输入贡献变化及匹配删除对照
  --> 判断鲁棒性能否由实际剩余信息支撑
```

Q1提供原素材定位流程的可追溯性证据，Q2提供官方特征上的鲁棒预测证据，Q3提供固定模型的解释忠实性与专项回看证据。三者共同形成方法和验证闭环，不声称已经完成“Q1自提取特征直接输入Q2权重”的原始视频端到端系统。

## 13. 规模、待核验条件与审核后的工作边界

### 13.1 50MB限制必须在方法阶段考虑

Q1目前设计的三组float32主特征不压缩约16.30MB，另有映射和说明。按全题50,000,000字节保守预算，尚未扣除其他文件前，最多约33.70MB可留给Q2/Q3相关材料；如果全是float32参数，理论上约840万参数就会用完这一余量，实际可用更少。

因此主方法采用冻结文本编码器、紧凑下游网络，Q2/Q3共享同一学生参数；EMA教师和训练用辅助头不要求作为专项推理模型重复打包。**冻结权重仍占空间，不能因此宣称满足50MB。**

本稿不把文本隐藏维固定为768，也不要求Q2与Q1使用相同规模的BERT。优先在兼容词表的前提下评估紧凑文本编码器或压缩权重；模型一旦确定，train/valid/专项统一使用，压缩后的预测效果也必须重评。`bert-base-uncased`是兼容性核对候选，不是无条件确定的可打包方案。

题目未明确通用预训练权重可否仅给下载说明，因此不能默认豁免。若必须全部随附，最终方法实例必须在包含通用权重后满足体积；若获明确豁免，也需保存完整版本与获取说明。当前只有预算分析，没有真实权重包或体积验收结果。

### 13.2 已确定的方法与仍需实际证实的条件

| 已可作为本轮方法结论 | 审核后必须实际核验，不能本轮冒称完成 |
| --- | --- |
| 官方aligned贯穿输入，文本统一编码 | 选定分词器/词表与存储IDs的兼容性 |

### 13.3 本轮建议审核的六个决定

1. 接受aligned官方输入与统一兼容文本编码，Q1通过方法衔接而非直接拼训练数据。
2. 接受先遮蔽再编码、保留局部位置至融合后，并明确当前可用状态与真实人工P分离。
3. 接受“MSD分解 + 原观测来源跨注意力补偿 + 监督误差系数融合”为主线。
4. 接受一个EMA教师、两视图真实标签监督及有限一致性约束；不默认叠加原IMTD、Soft-MoE和EMC。
5. 接受按同样本同扰动完成题目三维规律实验，并用消融决定可选模块去留。
6. 接受Q3解释同一学生、归因回到实际输入来源，并把兼容性、时间映射与真实提交体积作为须实测的条件。
