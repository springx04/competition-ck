# Q2 最终方法：面向模态局部缺失的三模态情感预测

本文是 Q2 唯一的最终方法文档。`Q2_最终方法与实现.md` 已改名为本文件；早期的 `E题_Q2_模态局部缺失鲁棒情感预测方法_v1/v2_审核稿.md`、`E题_Q2_优化方案_v3_实验中.md`、`E题_Q2_优化实现说明_v2_实验中.md` 和服务器实现说明仍保留，用于研究过程、失败方案和复现审计，不代表最终模型结构。最终模型与论文数值以 [最终实验与交付报告](../report.md) 和 `Q2/results/final/` 的实际重载结果为准。

## 1. 任务、数据和证据边界

Q2 的输入是附件2的 50 个官方 aligned 位置上的文本、声学和视觉特征，输出三分类情感标签以及范围为 `[-3,3]` 的连续情感分数。类别顺序固定为 `Negative=0, Neutral=1, Positive=2`。最终只使用附件2 `aligned_50.pkl` 的 train/valid/test：3395/728/727 条；附件3的 30 条样本只用于无标签专项预测，附件4不用于 Q2 训练或选模，也没有额外数据集。

附件2的数据形状为 `input_ids: [N,50]`、`stored_attention: [N,50]`、`token_type_ids: [N,50]`、`audio: [N,50,74]`、`vision: [N,50,35]`。train/valid/test 的类别计数分别为 `[967,758,1670]`、`[206,184,338]`、`[207,158,362]`；三划分的样本 ID 和 `video_id` 均无交集，未发现标签符号不一致。完整数据审计见 `Q2/results/audit/data_inventory.json` 与 `Q2/results/audit/environment.txt`。

需要明确报告口径：本项目后期曾查看 test，并依据 test 探索结果采用八层 BERT，因此最终 test 是已观察 test 后的自适应探索结果，`selection.json` 将 `independent_holdout` 记录为 `false`。部署 seed=1111 固定；epoch 由 valid 选择；1112/1113 仅作固定配置复验，没有按 test 分数逐 seed 挑选部署模型。这个流程偏离了题目要求的 valid-only 结构选择，本文保留该限制，不能把 test 数值描述成严格的独立泛化确认。

## 2. 缺失状态的定义

记第 `t` 个 aligned 位置、模态 `m∈{T,A,V}` 的当前可用标志为 `U_tm`。文本位置在 `stored_attention=1`、token 不是 PAD/CLS/SEP 且不是 MASK 时才计为当前可观测；UNK 是有效文本内容。音频或视觉行只要任意维度非零就视为观测，整行零保持不可用。模型每次都从当前输入重新计算 `U`、结构位置 `J` 和 BERT attention，不从同一样本的干净副本读取被遮挡信息。

`J_t` 是有效文本槽位（包括被人工替换成 MASK 的槽位）或 A/V 至少一个模态有观测的并集。对于主缺失网格，目标模态组合为 `T/A/V/TA/TV/AV`，位置为 `front/middle/rear`，名义跨度为 `ρ∈{0.2,0.4,0.6,0.8}`，共 72 个场景。每个样本先取 `J` 的首末位置包络，区间宽度为 `max(1, floor(ρ×包络长度+0.5))`；只在目标模态原有观测位上实施删除。于是名义 `ρ` 与实际删除率不完全相同，结果同时保存 `deletion_rates.csv`、共同受损样本表和按实际删除率分层表。

文本缺失在词元输入端替换为 BERT MASK，并把该位置从 BERT attention 与最终文本池化中排除后重新编码；A/V 缺失将对应行置零并重新推断当前状态。训练中的原始视图和受损视图共享同一标签。clean 只表示“不追加人工删除”，仍保留原始数据中的自然零行；自然零行不能被解释为人工缺失或提取失败。

## 3. 最终网络

### 3.1 文本编码

文本编码器是本地保存的官方 `google/bert_uncased_L-8_H-256_A-4`，词表大小 30522、隐藏维度 256、8 个 Transformer 层、4 个 attention head，不使用 pooler。所有 8 个 Transformer 层参与微调，词嵌入、位置嵌入、token-type 嵌入及其 LayerNorm 冻结；计算 FP32，存储 FP16，attention 实现为 eager。对当前输入 `x`，编码器输出为 `b_t∈R^256`，文本位置表示为

\[
e^T_t=U_{tT}\bigl(b_t+\mathbf{1}_{\{U_{tT}=1\}}b_{CLS}\bigr),
\]

其中 `b_CLS` 是同一次受损输入得到的当前 CLS 向量。公式中的乘法表示只向已观测文本位置提供该表示；被 MASK、PAD、特殊符号和原始无效位置均不进入文本池化。训练期若没有受损视图，则可缓存 clean 文本；受损视图必须重编码。

### 3.2 音频、视觉位置编码

仅使用 train 中非零行拟合逐维均值与标准差：

\[
\tilde x_{tm} = U_{tm}\frac{x_{tm}-\mu_m}{\max(\sigma_m,10^{-6})},\qquad m\in\{A,V\}.
\]

均值、标准差、类别先验和 score 中位数均来自 train，并以 `Q2/results/final/q2_final/normalizer.npz` 的形式进入最终包。最终配置没有 z-score 裁剪、均值插补或样本删除；整零行在标准化后仍为零。

### 3.3 模态位置表示和观测掩码注意力池化

三路分别使用独立的

\[
h_{tm}=U_{tm}\,\mathrm{Dropout}_{0.3}
\left(\mathrm{GELU}(\mathrm{LN}(W_mx_{tm}+b_m))\right),
\quad h_{tm}\in\mathbb R^{128}.
\]

最终 `late_attn_tune` 的池化分数为 `a_tm = w_m^T h_tm + b_m^a`，只在当前观测位置计算 softmax：

\[
\alpha_{tm}=\frac{U_{tm}\exp(a_{tm})}{\sum_{s=1}^{50}U_{sm}\exp(a_{sm})},
\qquad z_m=\sum_{t=1}^{50}\alpha_{tm}h_{tm}.
\]

若某一路没有观测，`z_m=0`，并将模态存在标志 `g_m=0`。因此池化是“当前观测内容的加权汇总”，不是从缺失位置生成特征，也不是经校准的可靠性概率或因果贡献。

### 3.4 晚融合与双头输出

将三路池化向量和模态存在标志拼接：

\[
v=[z_T;z_A;z_V;g_T;g_A;g_V]\in\mathbb R^{387},
\qquad r=\mathrm{Dropout}_{0.1}(\mathrm{GELU}(W_fv+b_f))\in\mathbb R^{128}.
\]

分类和回归头独立：

\[
\ell=W_c r+b_c\in\mathbb R^3,
\qquad p=\mathrm{softmax}(\ell),
\qquad \hat s=3\tanh(w_s^Tr+b_s).
\]

类别为 `argmax(ℓ)`，不能按 `sign(ŝ)` 重写分类，也不能把预测为 Neutral 的样本强制改成 0。最终部署不含类别偏置、集成、教师一致性、MSD 分解、补偿分支、可靠性门控、GRU 或 A/V 专用分支。源码中的旧分支仍为历史实验代码；final 配置实例化的是晚融合注意力学生。

若 `U` 的三路全为空，网络不虚构内容：分类 logits 回退到 train 类别先验的对数，回归回退到 train score 中位数。全空结果是信息不可用时的先验基线，不是缺失恢复性能。

## 4. 训练目标和真实超参数

对一个视图，分类使用 train 类别先验生成的加权交叉熵，回归使用 `δ=1` 的 Huber 损失：

\[
w_c=\frac{\pi_c^{-0.5}}{\frac13\sum_k\pi_k^{-0.5}},
\qquad
L_{task}=\frac1B\sum_i w_{y_i}[-\log p_{i,y_i}]+\lambda_s\,\mathrm{Huber}_1(\hat s_i,s_i),
\]

其中最终 `λ_s=1.0`。实现是逐样本加权项的普通 batch 均值，不再除以 batch 内权重和。前两轮 warm-up 只用原始观测视图；第 3 轮开始，损失为原视图和一份人工受损视图的两项之和：

\[
L=L_{task}(x)+L_{task}(\tilde x).
\]

受损副本的训练采样在预热后以 0.5 概率从公开 72 场景均匀抽样，另 0.5 概率使用原课程；原始视图始终保留。原课程非预热阶段按轻/中/重三段（10/15/30）采样局部连续区间，包含 20% 不追加删除；轻段单模态 `ρ∈[.05,.20]`，中段单/双模态 `ρ∈[.10,.50]`，重段 `ρ∈[.10,.80]`。这些随机选择只依赖 seed、epoch 和 sample index，不读取 valid/test 标签来拟合。

| 项目 | 最终设置 |
|---|---|
| 交付候选 | `late_attn_tune`，BERT8 全 8 层微调，seed=1111 |
| 复验 | 同配置 seed=1112、1113；不按 test 逐 seed 选优 |
| 训练轮数 | 20；valid 检查第 5、10、15、20 轮；seed1111 选第 10 轮 |
| batch | train 32，评估 128，`drop_last=false`，`num_workers=0` |
| 优化器 | AdamW，主干峰值学习率 `1e-4`，BERT 学习率 `1e-5` |
| 学习率 | 前 2 轮 warm-up；之后余弦下降，主干末轮 `1e-5`，BERT 组保持主干的 0.1 倍 |
| 正则 | 矩阵和可训练 BERT 参数 weight decay `1e-4`；bias/LayerNorm 等一维参数为 0 |
| 其他 | betas `(0.9,0.999)`，eps `1e-8`，全局梯度范数裁剪 1 |
| 数值 | FP32；AMP、TF32、compile 均关闭 |
| 选择键 | 72 主场景 Macro-F1 最大，其次缺失 MAE 最小、clean Macro-F1 最大、clean MAE 最小、较早 epoch |

最终配置文件为 `Q2/configs/final_train.yaml`，选择元数据为 `Q2/configs/final_selection.json`。配置里保留若干历史 loss 字段是为了兼容统一 schema；最终晚融合路径不使用 MSD、span、calibration、consistency 等旧分支权重。

## 5. 评估协议

主缺失网格对每个场景独立在同一 split 全样本上前向一次，计算三分类 Accuracy、Macro-F1、Weighted-F1、每类 Precision/Recall/F1、回归 MAE 和 Pearson，然后对 72 个场景等权平均。72 个场景共享同一批样本，不能把 `72×N` 当作独立样本，也不能把所有场景拼接后计算一个 F1 代替场景平均。另行保存 damaged-only、共同新增删除样本、双模态同时受损、实际删除率分层和 8 个压力场景。

压力测试包括 `T_whole/A_whole/V_whole`、`TA_staggered_0.4`、`TV_staggered_0.4`、`AV_staggered_0.4`、`TAV_middle_0.4`、`TAV_middle_0.8`，全空输入单列。视频 ID 成组的 1000 次 paired bootstrap 只描述固定模型在这批视频上的条件不确定性，未校正多次试验或 test 自适应选模。

## 6. 一条真实输入到输出链路

以下链路来自真实的附件3输入 `附件3_20.pkl`，不是示意数据。`Q2/results/audit/attachment3_availability.json` 和 `Q2/results/final/q2_special_state.csv` 记录了状态，`Q2/results/final/q2_predictions_aligned.csv` 记录了输出。

1. 输入层收到 `text_bert` 的三行字段（`input_ids/stored_attention/token_type_ids`）和 `audio[50,74]`、`vision[50,35]`。该样本有 48 个结构位置；文本当前观测 48/48，音频 34/48，视觉 34/48；A/V 的 14 个不可用位置形成 9 个缺口，最长连续缺口为 4。文本没有 MASK。这里的“34”是 `q2_special_state.csv` 的当前观测计数，不把零行当作补偿内容。
2. 状态层据当前输入构造 `U∈{0,1}^{50×3}`：文本列保留 48 个有效 token，A/V 各保留 34 个非零行；`J` 是这些位置的并集。BERT 用当前 50 位 input_ids 和 attention 重新计算 8 层输出，A/V 用最终包的 train 标准化参数变换；不存在的行被置为零。
3. 表示层将三路观测行映射到 128 维，并分别计算 masked softmax 池化 `z_T,z_A,z_V`。由于三路均非空，融合输入是三个 128 维池化向量和 `[1,1,1]` 三个存在标志，维度为 387；此处没有生成 `B_comp`，最终模型的三路补偿计数均为 0。
4. 晚融合得到 128 维向量，分类头输出三类 logits，经 softmax 得到 `P(Negative)=0.0797458`、`P(Neutral)=0.3309882`、`P(Positive)=0.5892659`；最大概率为 Positive，连续头输出 `ŝ=0.3862153`。最终文件的四舍五入结果为 `Positive, 0.38622`。

附件3没有标签，因此这条链路只能说明实际输入状态、推理路径和预测结果，不能计算该样本准确率。池化权重和隐藏向量没有写入最终 CSV，不能从报告数字反推它们；如论文主图需要它们，须由同一最终包扩展 `return_details` 后重新验证，不能用历史 MSD/补偿量替代。

## 7. 失败方案、观察与解释

以下结论区分“观察”（保存结果直接支持）和“推断”（对观察的机制解释），全部实验都发生在 test 已被查看后的探索流程，不能作为独立 holdout 证据。

| 方案 | 观测结果 | 结论与原因分析 |
|---|---|---|
| 历史 full/MSD—补偿—可靠性融合 | ledger 三 seed test 缺失均值约 0.4963，clean 约 0.5271 | 观察上低于晚融合；推断旧分支在零行和局部连续缺口上引入更多学习目标与误差传播，不能把复杂度本身当作收益。 |
| 历史 `late_clean` / `late_aug` | test 缺失约 0.4981/0.5113，clean 约 0.5221/0.5376 | 仅用 clean 或早期增强不足以覆盖局部缺失；这是具体训练课程失败，不排除其他课程。 |
| 原课程晚融合基线 | 三 seed test 缺失 0.559022，clean 0.593276 | 作为对照；提示训练期缺失课程有效但未达到缺失均值 0.60。 |

## 8. 局限和适用边界

1. test 已参与后续结构方向和候选探索；即使每个 checkpoint 的 epoch 由 valid 选定，也不能恢复独立 holdout 的统计含义。
2. 部署 seed=1111 固定；epoch 由 valid 选择；1112/1113 仅作固定配置复验。三 seed 的波动显示结果仍受 seed 影响，不应给出跨 seed 的显著性承诺。
3. PKL 没有原始时间戳、帧到词映射或特征提取版本。当前代码只能证明存储索引、tokenizer 和形状一致，不能证明物理逐词时间对齐完全正确。
4. 附件3没有标签，30 条输出不能计算准确率；其中 0 条出现文本 MASK，29 条 A/V 可用位置完全相同，说明实际缺口分散且不必然是单个连续块。原始零行究竟来自人工删除还是提取过程无法由附件判定。
5. 72 场景平均不是对真实缺失分布的无偏估计；它是本项目预定义的 72 场景评估网格。题目要求评估局部缺失及规律，但未规定这 72 个具体组合。附件3的分布与训练课程也不完全相同。
6. Q2 最终包约 27.14 MB zip、解压约 30.25 MB，只核验 Q2 单目录小于 50 MB，尚未验证 Q1+Q2+Q3 全题合包大小。
