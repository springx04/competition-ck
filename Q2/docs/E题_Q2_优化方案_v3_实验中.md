# Q2 优化方案 v3：文本微调、融合简化与 test 探索复核

2026-09-25 更新。状态：实验中，已有探索性 test 完整输入超过 0.60，72主缺失场景均值仍低于 0.60；不得作为最终方法优越性结论。本文补充并在下列事项上替代方法 v2：冻结策略、探索变体、训练周期、选模证据。v2 的数据划分、缺失定义和禁止信息泄漏要求继续有效。首次 test 已被查看，此后的探索及 test 复核不得称为全程未见测试集的独立确认；具体更正见第8、12节。

## 1. 目标与比较口径

在原三分类任务上争取尽可能高且可复核的性能，0.60 是最低优化目标，不是达到后立即停止的上限。主选模指标仍为 valid 上固定局部缺失网格的有效场景等权平均 Macro-F1；完整输入 Macro-F1、各类 F1、Accuracy、Weighted-F1、MAE 分开报告。不能把完整输入分数替换成缺失网格分数，也不能用二分类指标替代三分类指标。

保留附件2官方 train/valid/test=3395/728/727。归一化和类别先验只来自 train；梯度拟合只使用 train。每批候选在训练前明确配置，各自用 valid 选择 checkpoint，随后都读取同一 test 的完整输入和72主缺失场景，不因 valid 增益小就取消 test 复核。test 用于本轮目标评估及后续方向判断，整个过程明确标为自适应探索；不得将 test 标签用于训练、修改标签或数据划分。附件3/4不参与训练和调参。网上约 0.66 的三分类参考值按用户提供的参考处理，其数据划分与缺失条件未确认，不据此宣称本项目应取得同分。异常高分触发数据、代码和评估核查，不人为压低真实分数。

## 3. 候选方法

保持小型 BERT（4层、256维、同一词表）和官方50位置输入，允许低学习率端到端微调。该选择不增加编码器参数量，并继续考虑全题附件体积约束。训练、验证、部署必须使用同一模型的文本权重。

比较以下融合结构：

1. `late_tune` / `late_tune_balanced` / `late_tune_aug`：保留每模态两层Transformer，按当前观测掩码池化，再拼接三模态表示及可用标记，经128维投影输出分类和回归。
2. `late_pool_tune` / `late_pool_tune_aug`：去掉额外模态Transformer；各模态逐位置Linear→LayerNorm→GELU→Dropout(0.3)，掩码均值池化后执行相同晚融合。BERT仍提供文本上下文。
3. `late_attn_tune`：将轻量结构的均值池化替换为可学习的逐模态注意力池化，仅观测位置参与归一化。可选将当前受损输入的 BERT CLS 表示加到观测文本 token；特殊位置和缺失位置保持零。该选项必须随模型恢复，不能对历史所有模型默认开启。

上述晚融合候选均不使用MSD、跨模态补偿和EMA教师，不能沿用原full模型的补偿解释。Q3应诚实使用各自的实际中间表示，不能输出虚构的补偿贡献。原full及原十变体保留为历史方法及消融对照，不将新候选悄悄填入原表。

新增 `full_tune` 保留原完整跨模态补偿网络并微调 BERT；`full_tune_stress` 在同一结构上提高文本和双模态缺失的训练采样比例。二者属于探索变体，不等同于原 `full`。完整网络初步 valid clean Macro-F1 约0.585、缺失平均约0.54，尚未达到0.60目标；是否采用必须由缺失指标和多种子复核决定。

当所有模态都无观测内容时，即使仍存在文本MASK槽位，也回退到train类别先验及train得分中位数；仅凭结构槽位不能声称存在可供预测的内容。

## 4. 训练与优化方向

目标为 CE + λ·Huber，λ通过明确命名的对照实验比较。类别权重可选 train先验的负幂 `prior**(-p)`，再除以类别权重均值；p=0为无权重，p=0.5为温和校正。是否有利于Neutral类别必须由各类F1和整体性能证实。

下游学习率与BERT学习率分别设置，使用固定组比例、共同预热及余弦下降。短实验默认20轮、预热2轮，每5轮在完整固定网格评估一次；所有候选以相同主指标选checkpoint。默认下游峰值3e-4、BERT峰值3e-5只是探索起点，不能把未经比较的值写成最终最优参数。

有增强的候选在预热后依次覆盖轻度单模态、中度单/双模态、严重单/双模态缺失；阶段长度按总训练轮数缩放。原60轮预热5轮对应原来的第6–15、16–30、31–60轮。20轮实验不能仍等到第31轮才启用严重缺失。

下一批优先比较轻量融合、适度降低文本学习率、类别校正和完整缺失课程。先筛选配置，再对有希望的配置复验种子1111/1112/1113；不只保留最好种子。探索次数和失败结果均保留，避免将反复查看valid产生的乐观偏差当作独立泛化证据。

## 5. 对齐与真实性边界

已有核查未发现split间样本ID或视频ID重叠、标签符号映射错误、明显的整体padding偏移。进一步只读核查发现：三划分的input_ids、attention_mask、token_type_ids均能以同一WordPiece tokenizer完全重建；train/valid/test分别2850/622/597个相邻重复子词边的音频和视觉行全部一致；CLS、SEP及首个padding位置的AV行均为零。MMSA-FET参考实现也采用词区间聚合后按word_ids复制到子词、特殊token写零的逻辑。这些证据支持存储索引轴一致，目前没有发现明确的CLS/SEP偏移或子词展开错误。

该核查不使用test的模型预测表现调参。参考提取代码与文件特征一致，并不证明附件一定由该版本代码生成。PKL缺少词时间戳、原帧映射及生成配置，不能证明每行特征对应了正确的物理词区间。全零行也无法完全区分合法零值、提取失败与缺失，不能把全零视觉写成“原视频没有视觉内容”。

采用官方序列坐标，不凭猜测整体移动音视频特征。若原始提取映射无法恢复，应在报告中说明无法验证物理逐词对齐；晚融合对逐位置严格对齐的依赖较低，但这不是证明原数据无问题的依据。

## 6. 数据质量处理候选

截至本轮审计，train/valid/test 的 input、audio、vision、标签均未发现 NaN 或 Inf。音频、视觉的零行比例分别约为 54.8%/57.2%/56.2% 和 57.1%/58.0%/56.9%；这些零行是当前模态不可用状态，不能用均值填充后再标为已观测。train/valid/test 类别计数分别为 `[967,758,1670]`、`[206,184,338]`、`[207,158,362]`，存在轻度分布差异，不能通过测试标签重采样修正。

音频第0维出现约500的值，但审计显示它是单独的高范围特征维，未见 NaN/Inf；不能仅凭整体最大值删除。原训练归一化按训练集中非零行逐维估计均值和标准差，并将不可用行置零。新增 `data.clip_z` 候选只在归一化后的训练/验证前向中对已观测值做对称 z 分数裁剪，默认不启用；裁剪阈值应作为独立验证配置，不能改写原始 `.npy`。

训练文本内部有7个重复文本组（20行），短语如“Hi”“Okay”“Hello”出现不同情感标签；train/valid有2个完全相同文本但标签冲突的跨划分样本。它们更可能反映不同视频语境而非可直接删除的错误。当前不按文本去重，不用valid文本筛训练集；若后续做去重对照，必须仅基于train内部规则并单独报告。

## 7. 达标与最终交付条件

达标以 test 三分类指标为准，完整输入和主缺失均值分开判断；不要求 valid 先达到目标才允许 test 评价。候选配置和checkpoint选择遵循第1节规则，多个种子、各类表现及严重缺失退化仍需核查。选定交付方案后还需完成附件3预测、离线导出与包体积核验。任何尚未完成的环节明确写未完成。test低于valid或新候选退步时如实报告；后续依据已见test继续探索不恢复独立留出性质。第8–11节的“暂不采用”“不再次评价test”为当时状态，后续执行以第12节及之后记录为准。

## 9. 音视频重复计权与时序表示对照

新增两项分开评估的候选，均沿用注意力参考配置（seed1111、20轮、BERT lr=1e-5、下游lr=1e-4、回归权重0.25、类别权重p=0.5、CLS上下文）。不使用embedding解冻或强化文本缺失课程，不新增数据集，不改变评估网格和主选模指标。

`late_attn_runweight_tune`：在当前输入的归一化音频、视觉特征中，连续且完全相同的已观测行视为一个计权组，每行池化先验权重为该组长度的倒数，将其对数加到注意力分数后再softmax。缺失行打断组，不能跨缺失区间合并，也不能借用clean视图确定受损视图的权重。文本分支不作此处理。该候选保留U、J、原序列行和样本，不是删除数据或证明重复行错误；它只检验词级特征复制到子词后重复计权是否影响预测。默认不与z分数裁剪组合。

`late_gru_tune`：在音频、视觉逐位置MLP后分别增加一层双向GRU（单方向64维），只将当前已观测行按原先后顺序送入GRU，再散回原50位置。GRU输出与对应MLP特征残差相加、LayerNorm后进行原注意力池化；文本分支保持原样。无观测行输出零，整样本无观测时仍回退训练先验。该结构建模可观测片段的先后关系，不声称压紧后的相邻行在真实时间上连续，也不恢复缺失内容。Q3若解释该模型，需要说明每行表示包含其他可观测位置的时序上下文。

两者均属于待验证探索，不能以测试通过或结构合理直接宣布有效。

## 10. 文本缺失专用分支对照

`late_av_tune` 在文本至少有一行观测时使用原注意力晚融合投影；当文本模态完全不可用时，使用独立的同维 A/V 投影头。该头不改变U/J、原始位置或文本编码，不从clean视图复制信息。它针对文本完全不可用设计；对文本仍部分可用的T、TA、TV主场景不会直接启用专用头，不能将它当作局部文本缺失的普遍补救。20轮seed1111最佳第15轮，valid缺失0.557127、完整0.583849：相对`attn_tune_v3`缺失小幅升高、完整输入下降，当前不采用。

此前`late_attn_runweight_tune`最佳valid缺失0.552247、完整0.584071；`late_gru_tune`最佳valid缺失0.553855、完整0.590568，均不采用。GRU对照将可观测音视频行按原序压紧后建模再散回位置，未使用测试标签。三类结构实验均保留失败结果，避免把合理的结构假设写成有效方法。

在已观察test历史的前提下，按valid固定72场景和clean等权目标选择seed1113第15轮及偏置`[-0.4,0.05,0.05]`，得到探索性test clean=0.605201、72主缺失平均=0.566883。三类clean F1为0.661972/0.413793/0.739837；不称为独立留出确认。原始无偏置seed1113 test为0.591396/0.558175。此前摘要误写缺失为0.566071和0.557457，已按原始CSV精确匹配72主场景更正；新推理重算与这些原始CSV一致。

网上攻略中的词元级文本遮挡和局部连续缺失已由现有实现满足，但不能据此推定门控一定有效。新增`late_gate_tune`让每个样本根据三路池化内容和可用标记产生softmax门控，但20轮seed1111最佳valid缺失0.552884、完整0.589193，未优于无门控注意力。门控权重不等于经过校准的可靠性概率，该失败也不代表所有门控方法均无效。重建/CVAE/超图与大型预训练集成暂不采用：尚无本项目的受控收益证据，增加结构和容量需单独验证。禁止额外数据集不自动等于禁止所有预训练模型，合规范围应以题目和已批准来源为准，不能以此虚构禁令。

## 11. 攻略审查、专项输入形态和分布覆盖对照

“文本唯一敏感”不作为结论。现有valid结果只支持文本缺失退化较明显；要称为“唯一”，仍需同等实际删除率下对A/V的配对分析。全模态无内容时回退train先验，固定预测类别c的三分类Macro-F1为`2*n_c/(3*(N+n_c))`，不是普适的0.147。不得把全空回退分数与其他缺失场景混作一个来源不明的指标。

对附件3的只读输入审计（无标签、不训练）发现：30条对齐样本均未发现文本MASK；29条A/V可用位置完全相同。内容位置内音频和视觉零行比例的逐样本均值分别为20.6745%和21.0912%，各样本为0–50%；最长连续缺口至多4个位置，最多9个独立缺口。附件3_20为48个内容位置中14个不可用位置、9个缺口；附件3_30为24个位置中12个不可用位置、6个缺口。原始文件没有完整参照，无法判定每个零行是人工删除还是提取失败，也不能从未出现MASK证明转写从未缺字。这说明“实际缺失必为单一连续块”的说法不成立。审计脚本为`scripts/audit_special_missing.py`；附件3不用于选择超参数或作为有标签性能证据。

当前课程与72场景的支持范围大体重合，但概率不相等：课程使用随机起点、连续rho，评估对前/中/后、四个rho及六种模态组合等权。新增默认关闭的`train.grid_mix`对照：预热后，50%受损副本按公开72主场景均匀抽样，50%保持原课程；原观测副本始终保留。第一批只改变这一开关，不叠加text-stress、门控或类别偏置；不访问test记录或标签、不改评估场景权重。这一对照不能解决附件3离散缺口形态，也不据其统计定制训练。

## 13. 单模态辅助分类对照

新增`late_aux_tune`，在原注意力池化的文本、音频、视觉128维向量上分别增加三分类线性头。它只在训练时使用，目的是检验逐模态监督能否帮助缺失情况下的情感表示；不做特征重建、不引入额外数据集，也不把单模态分类输出融合到最终预测。每个模态仅对当前有观测内容的样本计算带原类别权重的CE，先求该模态样本均值，再在有样本的模态间等权平均。不能将“该样本模态缺失”当作带标签的零向量去监督辅助头。

预热期只加原观测视图的辅助损失；预热后加原观测和受损两路辅助损失。总损失为原联合分类/回归损失加`w * (L_aux_clean + L_aux_corrupt)`，其中预热期不含受损项。三个预先确定的权重为0、0.05、0.2，均使用seed1111、20轮、预热2轮、BERT lr=1e-5、下游lr=1e-4、回归系数1、类别权重指数0.5、CLS上下文及网格混合。每个候选均先按valid缺失指标选checkpoint，再评估完整test和固定72场景；不根据valid变化幅度决定是否读取test，不增加类别偏置搜索。

辅助头在公共模块之后初始化，并恢复公共随机数状态，减少零权重对照的额外差异。零权重与原`attn_gridmix_reg1_v1`全20轮总损失最大差约4.01e-8，test分类指标相同。这支持该对照保留原模型的数值行为，不声称逐位训练完全一致。辅助头共增加1161个训练参数，导出时删除；“无推理参数增加”仅指辅助头，不能忽略原BERT成本。

## 17. 附件2完整特征教师的训练期蒸馏探索

这是新增训练辅助方案，明确替代旧实现书“不得把附件2预计算text作为另一训练入口”在**训练教师**这一事项上的限制；学生的训练输入、受损valid/test和专项推理仍统一从当前`text_bert`重新编码。原题允许使用赛题附件2 train/valid及开源预训练模型，本方案没有增加数据集、下载模型或使用附件3/4拟合。教师绝不作为最终缺失预测器，也不参与学生推理。

已核查附件2的`text`为train `(3395,50,768)`、valid `(728,50,768)`，同一样本索引可由ID与现有处理数组逐一对应。其全部50行都非零，包括`text_bert`中的padding/special ID对应位置；不能据此称为有效token，也没有编码器、层及逐WordPiece映射元数据。教师因此将50个文本特征向量整体作为独立序列进行注意力池化，不套用token ID掩码、不假定第一行为CLS、不做逐token特征蒸馏；音频和视觉分别按自身非零行独立池化。只把样本级logits和连续得分作为学生训练目标，不假定三路逐行物理时间一致。

教师`feature_teacher_v1`使用与注意力晚融合相同的轻量结构，仅文本投影输入改为768维；train监督CE+Huber、回归系数1、train类别权重指数0.5、学习率3e-4、40轮、预热2轮、seed1111。每轮用valid完整输入Macro-F1选择教师，最佳第3轮，valid完整0.618544、MAE 0.589756，训练约30.7秒。它比学生更频繁地选轮，且读取另一种预计算文本表示，因此该数字不能当作严格结构消融收益，更不是学生test性能；尚未对这个仅训练期教师做test评价。

只导出3395个train样本的教师logits/score，并验证ID与训练样本顺序一致。学生在预热后受损视图上增加已有置信度加权一致性项：`w_i = p_teacher(y_i) * exp(-abs(s_teacher-y_score)/6)`，损失为`mean(w_i * (KL(p_teacher || p_student_corrupt) + Huber(s_student_corrupt, s_teacher)))`，教师两类输出均停止梯度；仍保留原观测和受损两路真标签监督。前2轮不加一致性，第3轮起在10轮内线性增加系数。
