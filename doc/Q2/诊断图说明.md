# Q2 最终模型诊断图

两张图均基于附件2官方 `test` 划分的727条样本，并由最终导出的 `q2_final.zip` 包重新加载推理生成；不是训练 checkpoint 的读数。

## 三分类混淆矩阵

![Q2 clean test confusion matrix](../../Q2/results/final/figures/test_clean_confusion_matrix.png)

图中行为真实类别，列为预测类别；每个单元格同时给出样本数和真实类别行内比例。中性类共有158条，只有59条（37.3%）被正确识别；23条（14.6%）被推向负向，76条（48.1%）被推向正向。由此可直接解释中性类F1偏低（0.4260）：模型对中性情感的判别边界偏向两侧，且更常偏向正向，而不是把中性误认为单一的负向类别。

## 回归预测散点图

![Q2 clean test regression scatter](../../Q2/results/final/figures/test_clean_regression_scatter.png)

横轴是真实连续情感强度，纵轴是模型回归预测。灰色虚线为理想预测 $y=x$，红线为测试集最小二乘拟合。横轴仅加入固定的极小视觉抖动，避免相同标签的点完全重合；计算指标仍使用未抖动的原始数值。最终包重推理得到 Pearson $r=0.608102$、MAE $=0.684072$，与最终报告一致。红线斜率小于理想线，反映预测强度存在向中心收缩的趋势，极端正/负情感的绝对强度更容易被低估。

逐样本预测及图形源数值见 [`test_clean_predictions.csv`](../../Q2/results/final/figures/test_clean_predictions.csv)，混淆矩阵和指标见 [`test_clean_diagnostics.json`](../../Q2/results/final/figures/test_clean_diagnostics.json)。图形生成命令为：

```bash
cd Q2
python scripts/generate_final_diagnostics.py --device cuda:0
```
