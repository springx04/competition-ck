# Q2 最终方法与实现

本文和 `report.md` 是最终论文入口，取代早期“MSD—补偿—可靠性融合”作为最终方法的表述。早期方案和探索文档保留研究过程，不是最终模型结构。最终采用 **八层小型 BERT 全 Transformer 层微调、观测掩码注意力池化、晚融合与分类回归联合学习**。采用单模型、seed1111；另外两个种子用于复验，不逐种子挑选 test 最优值。最终数值以 report 中离线重载模型的实测结果为准。

## 数据和预测任务

只使用赛题附件2官方 aligned_50 划分：train3395、valid728、test727。训练只用train梯度和标签，valid选择检查点。test已多次被查看并影响后续架构探索，因此最终指标是同一官方test上的自适应探索结果，不能称未见测试集的一次性确认。原题明确要求在valid选择结构、超参数与阈值，本次依据test采纳八层结构已偏离这一选模条款；经用户明确选择，报告以较高test模型为主并披露该偏离，不能宣称完整满足原题的实验选模流程。附件3的30个样本只用于最终预测，附件4不用于Q2训练或选模；没有额外数据集。允许的开源预训练BERT来源见 `../../Q2/THIRD_PARTY.md`。

类别顺序固定为0负向、1中性、2正向，连续情感分数范围[-3,3]。分类头与回归头独立；不能按预测强度符号改写分类，也不能把预测中性强制置为0。报告三分类Macro-F1、Accuracy、Weighted-F1、每类Precision/Recall/F1、MAE、Pearson相关；0.60指完整输入test目标的实现，不表示72缺失场景均值也达到了0.60。

## 当前输入状态和缺失定义

三路统一存储在50个官方aligned位置，但不声称每个位置对应相同长度的真实时间。文本使用赛题`text_bert`中的WordPiece ID、attention及token_type；声学74维、视觉35维。文本已观测位是attention=1且ID不为PAD/CLS/SEP/MASK的位置；UNK是已观测内容。音视频的每行只要任意分量非零就视为已观测，整零行保持不可用。可用掩码记为 $U_{tm}$。

结构位置 $J_t$ 是有效文本槽位（可包括MASK）或音视频已观测位的并集。人工缺失区间按原始结构位置的首末端点包络定义，在目标模态原已观测位上实施；自然零行不计为新增删除。正rho的区间宽度按floor(rho×包络长度+0.5)取整、至少1个位置，并不超过包络长度。前/中/后区间及名义跨度0.2/0.4/0.6/0.8的实际删除比例可能不同，报告提供damaged-only、共同受损样本、同实际删除率分层，不能直接将名义rho当成所有样本真实内容删除率。

文本删除在**词元输入端**替换为MASK，并将该位置从BERT attention和最终观测池化中排除，然后重新编码受损序列。绝不使用完整文本的上下文向量冒充受损文本，也不只把事后向量置零。音视频删除位置置零后重新计算当前可用状态。所有推理状态只由当前输入确定，不从干净副本读取缺失内容。训练原观测和人工受损两路共享标签，标签表示同一视频片段的情感。

## 网络及输出公式

文本编码器为官方 `google/bert_uncased_L-8_H-256_A-4`：8层、隐藏维256、4头；全部8个Transformer层参与微调，词/位置/type embedding及其LayerNorm冻结，不使用pooler。使用当前输入的末层token向量加当前CLS向量，仅保留已观测文本位置。音视频先按train已观测行的逐维均值、标准差标准化；标准差小于1e-6的维度将分母改为1，原始零行仍为零。最终没有z裁剪、插补或样本删除。

三模态各用独立 Linear($d_m$,128)→LayerNorm→GELU→Dropout(0.3) 得到位置表示 $h_{tm}$，并乘以 $U_{tm}$。对每个模态，用线性打分器得到 $a_{tm}$，只在已观测位计算softmax：

\[
\alpha_{tm}=\frac{U_{tm}\exp(a_{tm})}{\sum_{s:U_{sm}=1}\exp(a_{sm})},\quad z_m=\sum_t\alpha_{tm}h_{tm}.
\]

无观测模态的 $z_m=0$。拼接三路128维池化向量与3个模态是否存在的标志，得到387维输入，再经Linear(387,128)→GELU→Dropout(0.1)。分类输出3维logits，回归输出 $3\tanh(w_s^Tz+b_s)$。部署无类别偏置、无集成、无教师、无MSD、无重建补偿和可靠性门控。注意力分数只是模型内池化权重，不是因果贡献或经校准的可靠性。

当三模态所有内容都不可用，分类回退train类别先验，回归回退train强度中位数；MASK槽位不算可用内容。全空结果由先验决定，不能解读为模型恢复了情感信息。

## 优化目标和训练设置

每个视图的损失为加权交叉熵加Huber回归损失（delta=1、回归系数1）。类别权重 $w_c=\pi_c^{-0.5}/\operatorname{mean}_k(\pi_k^{-0.5})$，先验 $\pi$ 只来自train。交叉熵实现是逐样本加权值求普通样本均值，并非除以批内权重和。预热前两轮只训练原观测视图；之后总损失为原观测与人工受损两路损失之和（不是两者平均）。不加入辅助分类或教师一致性。

| 项目 | 最终设置 |
|---|---|
| 训练长度 | 每个种子20轮；seed1111按valid选择第10轮，不使用最后一轮替代 |
| 种子 | 1111为交付；1112、1113用于固定配置复验 |
| batch | train32，评估128；drop_last=false，num_workers=0 |
| AdamW | 下游峰值1e-4，BERT峰值1e-5；betas=(0.9,0.999)，eps=1e-8，weight_decay：下游矩阵和所有BERT可训练参数1e-4，下游bias及LayerNorm等一维参数0 |
| 调度 | 前2轮预热；共同余弦下降，下游末轮1e-5，BERT组保持0.1比例 |
| 稳定性 | 全局梯度范数裁剪1；FP32计算，AMP/TF32/compile关闭 |
| checkpoint选择 | 第5、10、15、20轮评估valid；优先72主场景平均Macro-F1，再缺失MAE、完整F1、完整MAE，最后更早epoch |
| 增强 | 原观测副本始终存在；预热后受损副本50%从72公开场景均匀取样，50%原课程 |

原课程在非预热阶段按10:15:30比例分成轻/中/重阶段，包含20%不追加删除；轻阶段单模态rho∈[.05,.20]，中阶段单/双模态rho∈[.10,.50]，重阶段rho∈[.10,.80]，双模态概率中/重为.2/.4，重阶段双模态有.1概率采用错位区间。该抽样只依赖种子、epoch、sample_index，公开评估规则不读取test样本来拟合。训练有全空回退，但不是靠整模态dropout替代局部连续块实验。

## 评估、复现与交付

主网格是6类目标模态（T/A/V/TA/TV/AV）×3位置×4跨度=72场景，每个场景独立在同一727个test样本上计算固定三类Macro-F1，然后72场景等权平均。不能把52,344条相关预测当作52,344个独立样本，也不能把全部场景拼接计算F1代替该平均。clean只指不追加人工删除，原始自然缺失仍存在。另报整模态缺失、三模态局部缺失、错位双模态等8种压力测试，以及单独全空检查。

评估保留全样本和实际受损子集，位置/模态/跨度比较使用同组共同受损样本；区间不等于真实秒数。置信区间以来源video_id成组重采样，描述固定模型的条件不确定性，不校正此前test自适应选择和多次探索。

可复现命令、官方模型准备、预测入口、包体积及离线一致性结果都在 `report.md`。final_train.yaml只记录交付seed1111；1112/1113复验由命令覆盖seed并使用独立输出目录。配置来源是 `../../Q2/configs/final_selection.json` 和 `../../Q2/configs/final_train.yaml`。报告使用**实际交付包重载**的FP16存储/FP32计算权重评估；论文不能将FP32训练checkpoint分数与FP16包分数混写。模型权重与赛题数据在服务器保留，不提交GitHub；代码、配置、聚合证据和30条预测在 `Q2`；方案与报告放在仓库 `doc/Q2`。

## 对数据对齐和Q3的边界

所有三划分的词元ID、attention、type能由同词表重建；四层和八层完整词表顺序相同。AV重复子词行和特殊位置零行与官方aligned语义一致，但PKL缺少原始词时间戳和提取映射，不能保证物理逐词对齐已完全证明。晚融合对跨模态逐行严格一致的依赖较弱，不意味着数据完全无误。

Q3需要加载相同最终单模型、相同词表和归一化，解释当前输入。当前接口返回观测掩码及位置表示；池化权重虽在前向计算中存在但尚未作为返回字段提供，Q3若需该量必须先扩展并验证解释接口；最终模型没有补偿分支，因此补偿计数为0，不提供虚构的缺失内容恢复或补偿贡献。若Q3原设计依赖MSD/补偿，必须改为最终模型的真实前向与反事实输入重算。
