# Q1 自动多证据核验实验结果与对比报告

**报告日期：** 2026-09-26
**冻结正式基线：** `runs/q1_full_20260924`
**基础源码版本：** `da6c8e5bd553d0480ca941384ae20f279929872f`
**实验性质：** 候选证据生成，不进行生产写回

## 1. 结论先行

本轮实验**没有完全解决“对不齐”问题**，但已经把原来笼统的 51 条 `unverifiable` 拆分成了可以复核的证据等级，并形成了两个三模态强候选。

- 上次：51 条隔离样本全部只能统一描述为不可验证。
- 本次：2 条为三模态 `verified` 候选，10 条为 `partial`，39 条仍为 `uncertain`。
- 完全不确定样本从 51 条降至 39 条，减少 12 条，即下降 **23.53%**。
- 严格达到自动强候选的只有 2/51，即 **3.92%**。
- 正式 `paired_use=true` 仍为 49 条，实际生产提升为 **0**；只有在后续审核批准两条强候选后，才可能从 49 条增加到 51 条，即总样本覆盖率增加 2 个百分点，配对样本数相对增加 4.08%。

因此，最准确的表述是：

> 本轮显著提高了问题定位能力和证据覆盖，部分降低了不确定性，但没有建立人工金标准，也没有安全地解决大多数音文语义冲突和视觉身份歧义；正式 Q1 结果保持不变。

## 2. “对不齐”的分层定义

本项目中的“对不齐”并非单一问题，至少包括四层：

1. **结构与数值对齐**：样本索引、数组形状、CSR、source ID、mask、coverage 是否正确。该层在上次正式验收时已经通过。
2. **词时间对齐**：CTC 词区间是否和真实语音边界一致。本轮增加 WhisperX 独立诊断，但没有替换正式 CTC。
3. **文本—音频语义配对**：官方文本是否确实对应当前音频。该层仍是主要未解决问题之一。
4. **视觉身份与主动说话人配对**：OpenFace episode 是否属于目标说话人。该层只在少量样本上形成强候选。

本轮解决的是第 2–4 层的自动证据不足问题，而不是直接修改正式特征或宣布人工确认。

## 3. 实验方法

### 3.1 文本—音频证据

- 对全部 100 条样本运行 WhisperX 3.8.6，而不是只观察原 23 条告警样本。
- 固定使用 `large-v2`、Silero VAD 和 `WAV2VEC2_ASR_LARGE_LV60K_960H`。
- 保存转写、词时间、WER、CER、词重合率及 CTC/WhisperX 共同词边界差。
- 每条样本从不同 `video_id` 中选择不少于 20 条时长和词数相近的错误文本作为负对照。
- 阈值在查看结果前冻结，不使用情感标签，不以恢复样本最多为目标调参。

### 3.2 视觉身份与视听同步

- 使用 InsightFace `buffalo_l` 的 ArcFace 模型为全部 OpenFace episode 生成身份嵌入。
- 主身份阈值固定为余弦相似度 0.60，0.50 和 0.70 仅用于稳定性分析。
- 通过嘴部 landmark 构造视觉运动信号，通过 PCM 能量构造音频活动信号。
- 使用 ±0.5、±1.0、±2.0 秒时间平移及跨样本错误音频构造 AV-sync 负对照。
- 使用官方 TalkNet `pretrain_TalkSet.model`，保留 class-1 logit，并使用官方 `logit >= 0` 判据；TalkNet 仅作为辅助证据，不直接释放样本。

### 3.3 词级候选特征

从冻结 native 特征和正式 CTC accepted intervals 生成独立的 `q1_word_aligned_candidate.npz`，按真实时间重叠将音频和视觉特征聚合到词位置。该文件没有覆盖 `q1_compact50.npz`。

### 4.1 条件性覆盖提升

两个三模态强候选为：

- `-dxfTGcXJoc$_$1`
- `-lzEya4AM_4$_$6`

如果下一轮审核逐条批准这两条，严格配对样本可由 49 增至 51：

- 配对样本数相对增幅：2/49 = 4.08%。

这是**条件性上限**，不是本轮已经实现的正式提升。

- WhisperX：100/100 完成，失败 0；

## 6. 视觉身份与AV同步结果

### 6.1 37条身份风险样本

| 视觉等级 | 数量 | 占37条比例 |
|---|---:|---:|
| `V_STRONG` | 2 | 5.41% |
| `V_PARTIAL` | 8 | 21.62% |
| `V_UNCERTAIN` | 27 | 72.97% |

ArcFace 0.60 阈值下的 identity cluster 数分布：1个15条、2个14条、3个3条、4个3条、5个1条、9个1条。多数多 episode 样本仍不能仅依靠身份相似度和AV同步唯一确定目标说话人。

### 6.2 AV-sync

- 真实同步：n=118，P25/中位数/P75 = 0.0516/0.1785/0.3102；
- 错位负对照：n=3,041，P25/中位数/P75 = 0.0435/0.1399/0.2581；
- 中位数差：0.0386；
- 每个 cluster 相对自身错位分布的经验百分位中位数：0.5769；
- percentile ≥0.80：38 个 cluster；
- percentile ≥0.95：17 个 cluster。

真实同步总体优于负对照，但分布重叠明显，因此不能用单一相关系数自动释放全部身份问题。

### 6.3 TalkNet

- 官方 TalkSet checkpoint：63,227,827 bytes；
- SHA256：`d985ddd07dca08864a28337726f5b7d91b6426bebc7327f0e9b21cf9ff1cc937`；
- 487个参数键全部匹配，缺失、额外和形状错误均为0；
- 96条有人脸样本全部至少有一个有效 episode；
- 165/191 episode 成功，得到19,067条逐帧 logit；
- 26个失败 episode 均为0.033–0.100秒的极短碎片，没有伪造得分。

## 10. 尚未解决的问题

1. 39条三模态候选仍为 `uncertain`。
2. 10条只有部分证据，不能直接生产释放。
3. 原23条音文告警有19条仍为冲突，0条达到强证据。
4. 原49条正式配对样本中新发现1条冲突和1条时间部分风险。
5. 没有独立人工Gold，无法计算precision、recall、F1或真实对齐误差，也不能声称准确率提升。
6. MFA因缺少锁定环境、声学模型和词典而未运行；正式CTC保持不变。
7. TalkNet极短碎片没有有效输出，但96条有人脸样本均有其他有效episode。

## 11. 建议下一步

1. 优先审核两条三模态强候选，判断是否允许正式释放。
2. 逐条检查10条partial，重点查看建议可用视觉区间与应mask区间。
3. 对19条 `TA_CONFLICT` 及新增的 `-vxjVxOeScU$_$4` 运行MFA或人工听审。
4. 对 `-I_e4mIh0yE$_$3` 检查CTC边界，不要误判为文本音频错配。
5. 对27条 `V_UNCERTAIN` 保持隔离，除非获得明确视听证据。
6. 人工批准后才生成 proposed 配置并执行正式六阶段重算；本轮候选不能直接覆盖生产结果。
