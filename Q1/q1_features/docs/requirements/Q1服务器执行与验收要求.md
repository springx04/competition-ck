# Q1 服务器执行与验收要求（脱敏摘要）

本文是数学建模 Q1 多模态特征提取任务的脱敏需求摘要，不包含服务器地址、端口、账号、代理地址或其他连接信息。实际执行细节以项目配置、运行记录和操作指南为准。

## 1. 基本约束

- 使用指定项目目录、外部数据目录和已验收的隔离 Python 环境。
- 不删除、移动、覆盖或重新编码原始数据集。
- 源代码归档必须先验证 SHA256，`SOURCE_REVISION` 必须与预期版本完全一致。
- 已有模型和环境应先检查；只有缺失或不可用时才按固定版本补充。
- 不自行寻找或替换旧版代码包、模型、OpenFace 或特征定义。
- 环境问题优先修复环境；只有确认属于代码缺陷时才做最小修改。

## 2. 固定实现与模型

- 文本：`google-bert/bert-base-uncased`，固定不可变 revision，输出 768 维特征。
- 对齐：固定 ESPnet CTC 模型及 revision，只用于词级时间定位。
- 音频：openSMILE eGeMAPSv02 LowLevelDescriptors，25 维。
- 视觉：OpenFace 2.2.0 `FaceLandmarkVidMulti`，22 维。
- 聚合：每条样本 50 个相对时间窗口，coverage 按有效交叠区间并集计算。
- 正式完整运行时启用 Hugging Face/Transformers 离线模式，不临时切换模型版本。

模型 revision、依赖版本和 OpenFace 构建步骤见 [`../operations/服务器运行指南.md`](../operations/服务器运行指南.md)。

## 3. 数据准备要求

- manifest 为 100 行，`sample_id` 100 个且唯一。
- `video_id` 37 个且唯一。
- labels 和 sample index 均为 100 行。
- `input_status` 全部为 `ok`，缺失源视频为 0。
- 任一模态缺失或失败时仍须保留样本行、状态、原因和 mask，不得静默忽略样本。

## 4. 执行顺序

1. 校验代码版本和环境，运行 `pip check` 与全部单元测试。
2. 验证 OpenFace 2.2.0 二进制可以实际处理真实视频。
3. 验证所有固定模型能够离线加载。
4. 执行 `prepare` 和 `media`。
5. 选择短、中、长真实样本执行 `check-models` 和冒烟 `run --resume`。
6. 检查音频时间轴、BERT、CTC、openSMILE、OpenFace、native/pooled 形状、有限值、source_id、mask、status、reason 及视觉身份状态。
7. 冒烟测试通过后执行 100 条完整 `run --resume`。
8. 完成人工审核后依次运行：

```text
vision --reuse-raw-csv → audit → pool → collect → validate → report
```

## 5. 人工审核规则

- 对所有自动告警及项目要求的音视频案例逐项审核。
- 只有实际查看对应音视频、时间轴或人脸证据后，才能确认匹配或不匹配。
- 不批量伪造 `confirmed`，一条记录不得释放不对应的多个告警。
- 无法可靠确认时保持 `unresolved` 或 `unverifiable`。
- 人脸不匹配或模态无法配对时必须设置 `paired_use=false`。
- 保留具体问题 ID、时间区间、审核结论和证据说明。

## 6. 最终验收标准

- 单元测试全部通过，基线为 `31 passed`。
- 100 条样本全部存在于最终索引，且 zero `not_processed`。
- `reports/validation.json` 为成功状态且无错误。
- 数组形状、dtype、有限值和二值 mask 验证通过。
- CSR 结构、native source_id、必需时间轴、observed window 和 coverage union 复算通过。
- `reports/package_size.csv` 存在。
- 对齐问题包含具体 ID、时间区间和证据。
- 自然缺失或确认无法配对的模态保留 mask、status、reason，并设置 `paired_use=false`。
- 最终报告不得把 `unresolved` 或 `unverifiable` 描述为已人工确认。

## 7. 失败与恢复

- 使用断点续跑，不删除已经成功生成的中间结果。
- 单项失败时先定位具体样本和模态，不从头重跑全部任务。
- 未完成时必须记录失败命令、错误摘要、日志路径、已完成阶段及下一条安全恢复命令。
- 不允许通过删除、跳过或弱化测试绕过问题。
