# Q1 双盲审核与辅助诊断操作指南

## 1. 当前实施状态

本流程只解决 Q1 数据质量问题，不改变 BERT、CTC、openSMILE、OpenFace 或 50 窗口特征定义，也不训练情感模型。实验参数以 [`configs/q1_review_experiment.yaml`](../../configs/q1_review_experiment.yaml) 为准。多视觉片段、锚点词和金标准锁定的逐步命令见 [`Q1多片段与锚点词审核执行清单.md`](Q1多片段与锚点词审核执行清单.md)。

截至 2026-09-24，已完成：

- 为 100 条样本生成两份独立随机顺序的盲审表；
- 冻结原始告警、审核表、质量表作为基线快照；
- 实现审核表校验、一致率、Cohen’s κ、Krippendorff’s α 和按 37 个 `video_id` 分组的 10,000 次 bootstrap；
- 实现分歧、低置信度、`unverifiable` 和四条自动 `no_face` 样本的强制裁决队列；
- 实现 100 条最终决策到候选生产配置的安全转换，默认只写 `.proposed.csv`；
- 实现 CTC 风险排序。WhisperX 缺失时只使用两项 CTC 指标，并明确标记为未完成三分量诊断；
- 修正 `audit`：OpenFace 成功但零可用人脸时自动生成 `vision_no_face` 问题，防止音文审核释放后错误设为 `paired_use=true`。

尚未完成、且不能由自动程序代替：两名真实审核者的独立视听审核和第三人的裁决。TalkNet 官方源码已冻结，但官方权重下载失败；WhisperX 与 ArcFace 当前环境未安装，因此不得声称相应消融实验已经完成。

## 2. 盲审材料

工作目录：

```text
runs/q1_full_20260924/reports/review_experiment/
├── reviewer_a.csv
├── reviewer_b.csv
├── packet_index.csv
├── experiment_manifest.json
└── baseline/
```

审核者只能打开分配给自己的 CSV 和其中指向的真实媒体、音频、词时间轴、OpenFace 行及帧目录。第一轮不得查看：

- 情感标签；
- `paired_use` 与当前配对状态；
- `baseline/` 中的告警；
- 辅助模型分数；
- 另一位审核者的表格。

每条必须填写：

- `transcript_status`：`match`、`mismatch` 或 `unverifiable`；
- `visual_status`：`active_face_identified`、`no_visible_target`、`multiple_ambiguous` 或 `unverifiable`；
- `confidence`：1、2、3；
- `evidence_note`：实际观看和听取后的证据；
- 问题存在时填写精确的起止时间；
- 确认可见目标脸时填写 `face_id`、`episode_id` 及视觉起止时间。

不得使用空泛的“已查看”“看起来正确”作为证据，也不得用一条记录代替多条不同告警的结论。

## 3. 审核数据锁定和一致性分析

两位审核者各自提交后，先复制为只读快照并计算 SHA256，再运行：

```bash
export Q1_PY=/home/jqy/miniconda3/envs/shumo/bin/python
export REVIEW_DIR=runs/q1_full_20260924/reports/review_experiment

"$Q1_PY" scripts/review_workflow.py analyze \
  --reviewer-a "$REVIEW_DIR/reviewer_a.csv" \
  --reviewer-b "$REVIEW_DIR/reviewer_b.csv" \
  --run-dir runs/q1_full_20260924 \
  --output-dir "$REVIEW_DIR/analysis"
```

输出包括 `agreement.json` 和 `adjudication_required.csv`。若音文或视觉任一类别的 κ、α 低于 0.80，应先修订标注说明，再让两位审核者独立重审该类别的全部 100 条样本；不能只讨论分歧项来抬高一致性。

## 4. 第三人裁决

第三位裁决者必须处理队列内全部项目，并填写最终音文、视觉结论及证据。即使两位审核者一致，以下条目仍强制裁决：

- 任一低置信度；
- 任一 `unverifiable`；
- 四条自动零人脸样本；
- 时间区间、`face_id` 或 `episode_id` 不一致。

裁决完成后生成包含全部 100 条样本的最终决策：

```bash
"$Q1_PY" scripts/review_workflow.py finalize \
  --reviewer-a "$REVIEW_DIR/reviewer_a.csv" \
  --reviewer-b "$REVIEW_DIR/reviewer_b.csv" \
  --adjudication "$REVIEW_DIR/analysis/adjudication_required.csv" \
  --run-dir runs/q1_full_20260924 \
  --output "$REVIEW_DIR/final_decisions.csv"
```

## 5. 辅助诊断的解锁时点

只有第三方裁决完成且 `gold/gold_lock.json` 已锁定独立人工金标准后，才能解锁辅助输出。辅助模型只能定位时间段和排列候选，不能直接生成 `confirmed_match` 或 `confirmed_mismatch`。

先生成现有 CTC 风险排序：

```bash
mkdir -p "$REVIEW_DIR/auxiliary/audio_text"
"$Q1_PY" scripts/build_review_risk.py \
  --run-dir runs/q1_full_20260924 \
  --output "$REVIEW_DIR/auxiliary/audio_text/risk_ranking.csv"
```

如以后获得锁定的 WhisperX 输出，CSV 必须至少含 `sample_id,whisperx_wer`，然后使用 `--whisperx-csv` 重新生成三分量排序。旧文件应保留并使用新文件名，禁止覆盖基线。

TalkNet 官方实现输出的是类别 1 的 logit；其演示代码用 `score >= 0` 着色，因而本实验的显示阈值冻结为 0.0，而不是未经验证的 0.5。ArcFace 只在单条样本内连接跨镜头 episode，不用于判断谁正在说话。InsightFace 公布的 `buffalo_l` 权重仅限非商业研究使用。

## 5.1 人工金标准完成后的评价

只有 `final_decisions.csv` 已包含 100 条真实裁决后才运行：

```bash
"$Q1_PY" scripts/evaluate_review_results.py \
  --final-decisions "$REVIEW_DIR/final_decisions.csv" \
  --risk-csv "$REVIEW_DIR/auxiliary/audio_text/risk_ranking_ctc_only.csv" \
  --quality-csv runs/q1_full_20260924/reports/quality.csv \
  --output "$REVIEW_DIR/analysis/audio_text_evaluation.json"
```

评价器计算现有 CTC 告警的 confusion matrix、precision、recall、F1，风险排序的 AUPRC，原无告警样本中的漏报，以及 `false_release`；F1 与 AUPRC 的 95% CI 按 37 个 `video_id` 做 10,000 次分组 bootstrap。若不是恰好 100 条唯一最终决策，或三个输入的样本 ID 不一致，命令会拒绝运行。

## 6. 生成候选生产配置

该命令不会覆盖 `configs/`：

```bash
"$Q1_PY" scripts/review_workflow.py export \
  --final-decisions "$REVIEW_DIR/final_decisions.csv" \
  --baseline-alignment "$REVIEW_DIR/baseline/alignment_review.csv" \
  --output-dir "$REVIEW_DIR/proposed_configs"
```

必须由负责人逐行检查两个 `.proposed.csv`，确认 100 条最终决策、78 条原告警、四条 `vision_no_face` 以及人工新发现的漏报均已正确映射后，才可人工批准替换生产配置。自动脚本不会执行替换。

## 7. 批准后的重算与验收

配置获批后严格执行：

```text
vision --reuse-raw-csv
→ audit
→ pool
→ collect
→ validate
→ report
```

最终必须检查：100 条样本保留、zero `not_processed`、`validation.json.ok=true`、`errors=[]`，且 mismatch、no-face、ambiguous 与 unresolved 样本全部为 `paired_use=false`。安全指标定义为：

```text
false_release =
人工确认不匹配、无可见目标或仍不可验证，
但最终 paired_use=true 的样本数
```

要求 `false_release=0`。覆盖率仅作描述，不能以牺牲安全性为代价提高。

## 8. 方法依据

- [AVA-ActiveSpeaker](https://arxiv.org/abs/1901.01342)：按时间标注可听语音与主动说话人。
- [TalkNet](https://arxiv.org/abs/2107.06592)：音视频主动说话人候选排序。
- [ArcFace](https://openaccess.thecvf.com/content_CVPR_2019/html/Deng_ArcFace_Additive_Angular_Margin_Loss_for_Deep_Face_Recognition_CVPR_2019_paper.html)：身份嵌入与片段内身份连接。
- [CTC Segmentation](https://arxiv.org/abs/2007.09127)：给定文本和长语音的时间定位与低置信度筛查。
- [WhisperX](https://www.isca-archive.org/interspeech_2023/bain23_interspeech.html)：独立 VAD、转写和词级时间诊断。
- [Cohen’s κ](https://journals.sagepub.com/doi/10.1177/001316446002000104) 与 [Krippendorff reliability](https://onlinelibrary.wiley.com/doi/10.1002/bs.3830160305)：扣除偶然一致后的标注可靠性。
- [ModDrop](https://arxiv.org/abs/1501.00102) 与 [MissModal](https://aclanthology.org/2023.tacl-1.94/)：显式处理缺失模态，不能把填充值当成观测。
