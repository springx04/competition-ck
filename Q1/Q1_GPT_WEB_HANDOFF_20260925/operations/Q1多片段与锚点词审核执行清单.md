# Q1 多片段与锚点词审核执行清单

## 1. 当前边界

本清单用于完成 100 条样本的双人独立审核、第三方裁决和人工金标准锁定。人工金标准锁定之前，不运行 TalkNet、ArcFace 或 WhisperX，也不向审核者和裁决者展示辅助模型输出。程序不会自动填写人工结论，也不会把 `unverifiable` 转写为 `confirmed`。

固定路径：

```bash
export Q1_PY=${Q1_ENV}/bin/python
export RUN_DIR=runs/q1_full_20260924
export REVIEW_DIR="$RUN_DIR/reports/review_experiment"
```

当前已生成：

- `reviewer_a.csv`、`reviewer_b.csv`：每条样本的总体音文和视觉结论；
- `reviewer_a_segments.csv`、`reviewer_b_segments.csv`：可变行数视觉片段；
- `reviewer_a_anchors.csv`、`reviewer_b_anchors.csv`：33 条样本、每条 5 个预选锚点词；
- `anchor_sample_selection.csv`：管理员抽样审计表，不发给审核者；
- `template_archive/`：启用多片段表之前的两份空白总体表快照。

锚点子集由全部 23 条现有音文告警和 10 条无告警对照组成。10 条对照按 CTC 风险五分位各取 2 条，固定种子为 2026，并优先使用不同原视频。实际结果为 33 条样本、165 个锚点词。

## 2. 填写规则

两位审核者分别填写自己的三份表，且第一轮不得查看 `baseline/`、`anchor_sample_selection.csv`、另一审核者表格或 `auxiliary/`。

视觉片段表固定字段为：

```text
sample_id,segment_id,start,end,visual_label,face_id,episode_id,confidence,evidence_note
```

`visual_label` 只能是 `active_speaking`、`visible_not_speaking`、`no_visible_target`、`multiple_ambiguous`、`unverifiable`。每条样本至少一行；同一目标出现多个说话片段或跨镜头 episode 时必须逐行记录。`active_speaking` 和 `visible_not_speaking` 必须引用该样本 `vision_rows.jsonl` 中真实存在的 `face_id/episode_id`。

锚点词表固定字段为：

```text
sample_id,word_id,raw_word,gold_start,gold_end,confidence,evidence_note
```

不得更换预选词。无法听清时，`gold_start/gold_end` 留空、`confidence=1`，并在证据中明确写入英文标记 `unverifiable` 及原因。每条样本最多 5 个锚点词。

校验器会拒绝：媒体范围外区间、不存在的 OpenFace 身份对、重复片段、同一身份重叠片段、不存在的 `word_id`、词文本不一致和超过 5 个锚点词。

## 3. 锁定两位审核者原始提交

两人完成全部表格后，先创建不可覆盖的只读副本和 SHA256 清单：

```bash
"$Q1_PY" scripts/lock_review_submissions.py \
  --reviewer-a-summary "$REVIEW_DIR/reviewer_a.csv" \
  --reviewer-b-summary "$REVIEW_DIR/reviewer_b.csv" \
  --reviewer-a-segments "$REVIEW_DIR/reviewer_a_segments.csv" \
  --reviewer-b-segments "$REVIEW_DIR/reviewer_b_segments.csv" \
  --reviewer-a-anchors "$REVIEW_DIR/reviewer_a_anchors.csv" \
  --reviewer-b-anchors "$REVIEW_DIR/reviewer_b_anchors.csv" \
  --output-dir "$REVIEW_DIR/locked_submissions_20260925"
```

锁目录必须为新目录；脚本拒绝覆盖已有锁文件。

## 4. 一致性分析与裁决队列

先分析总体类别：

```bash
"$Q1_PY" scripts/review_workflow.py analyze \
  --reviewer-a "$REVIEW_DIR/reviewer_a.csv" \
  --reviewer-b "$REVIEW_DIR/reviewer_b.csv" \
  --run-dir "$RUN_DIR" \
  --output-dir "$REVIEW_DIR/analysis"
```

再分析视觉片段和锚点词：

```bash
"$Q1_PY" scripts/review_annotation_workflow.py analyze \
  --run-dir "$RUN_DIR" \
  --segments-a "$REVIEW_DIR/reviewer_a_segments.csv" \
  --segments-b "$REVIEW_DIR/reviewer_b_segments.csv" \
  --anchors-a "$REVIEW_DIR/reviewer_a_anchors.csv" \
  --anchors-b "$REVIEW_DIR/reviewer_b_anchors.csv" \
  --output-dir "$REVIEW_DIR/analysis"
```

视觉端点差超过 0.20 秒或 temporal IoU 小于 0.80 即进入裁决。四条自动零人脸样本即使两人一致也强制裁决。输出包含：

- `adjudication_segments_required.csv`；
- `adjudication_anchors_required.csv`；
- `adjudication_segments.csv`；
- `adjudication_anchors.csv`；
- `annotation_agreement.json`。

`adjudication_segments.csv` 对每个必裁样本采用“完整替换”语义：裁决者必须写入该样本全部最终视觉片段，不能只写分歧片段。

## 5. 生成并锁定独立人工金标准

先按总体裁决表生成 100 条最终总体结论：

```bash
"$Q1_PY" scripts/review_workflow.py finalize \
  --reviewer-a "$REVIEW_DIR/reviewer_a.csv" \
  --reviewer-b "$REVIEW_DIR/reviewer_b.csv" \
  --adjudication "$REVIEW_DIR/analysis/adjudication_required.csv" \
  --run-dir "$RUN_DIR" \
  --output "$REVIEW_DIR/final_decisions.csv"
```

随后合并片段和锚点裁决：

```bash
"$Q1_PY" scripts/review_annotation_workflow.py finalize \
  --run-dir "$RUN_DIR" \
  --final-decisions "$REVIEW_DIR/final_decisions.csv" \
  --segments-a "$REVIEW_DIR/reviewer_a_segments.csv" \
  --segments-b "$REVIEW_DIR/reviewer_b_segments.csv" \
  --anchors-a "$REVIEW_DIR/reviewer_a_anchors.csv" \
  --anchors-b "$REVIEW_DIR/reviewer_b_anchors.csv" \
  --adjudicated-segments "$REVIEW_DIR/analysis/adjudication_segments.csv" \
  --adjudicated-anchors "$REVIEW_DIR/analysis/adjudication_anchors.csv" \
  --agreement-dir "$REVIEW_DIR/analysis" \
  --output-dir "$REVIEW_DIR/gold"
```

成功后生成 `gold/final_visual_segments.csv`、`gold/final_anchor_words.csv` 和 `gold/gold_lock.json`。锁文件同时记录 100 条 `final_decisions.csv`、最终视觉片段表和最终锚点词表的 SHA256。只有 `gold_lock.json.status=independent_human_gold_locked` 后，辅助模型实验才可开始。

## 6. 多片段候选生产配置

```bash
"$Q1_PY" scripts/review_annotation_workflow.py export \
  --run-dir "$RUN_DIR" \
  --final-decisions "$REVIEW_DIR/final_decisions.csv" \
  --final-segments "$REVIEW_DIR/gold/final_visual_segments.csv" \
  --baseline-alignment "$REVIEW_DIR/baseline/alignment_review.csv" \
  --output-dir "$REVIEW_DIR/proposed_configs"
```

该命令可为同一样本输出多行 `target_face_segments.proposed.csv`，但仍不覆盖 `configs/`。负责人完成逐行审批后，才能进入：

```text
vision --reuse-raw-csv → audit → pool → collect → validate → report
```

TalkNet、ArcFace 或 WhisperX 缺失不会阻止上述人工流程和安全写回；只会使辅助消融表保持未完成。
